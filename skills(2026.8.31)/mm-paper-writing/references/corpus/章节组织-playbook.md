# 章节组织 playbook

> **定位：语料证据**（章节骨架统计与反例），不是操作规范；章节结构、篇幅与各块写法以 `references/common-paper-rules.md`、`references/writing-order.json` 与 `references/chapters/` 对应章节文件为准，冲突时以操作规范为准。

> 基于 28 篇国赛优秀论文语料(2020–2025)统计。2023 语料 12/13 篇可读篇目与 15 篇 OCR 篇目全部采用同一骨架。

## 1. 顶层章节骨架(八段式,跨 6 年 28/28 篇主链一致)

```
一、问题重述(1.1 问题背景 / 1.2 问题提出)
二、问题分析(逐问分析，不另设“各问之间的联系”等汇总小节)
三、模型假设(2–8 条,编号列表)
四、符号说明(表格)
五、模型的建立与求解(逐问成节:5.1 问题一 … 5.4 问题四)
六、模型的评价与推广(或「模型评价与改进」)
七、参考文献
附录(代码 / 支撑材料)
```

- **别自创大框架**:28/28 篇主链一致(重述→分析→假设→符号→分问建模求解→评价→参考文献→附录)。语料中存在不同的问题组织方式，但本工作流统一采用最主流的整体成章：`五、模型的建立与求解`下按问题顺序设置二级标题，内层按真实模型内容生成，不机械复制一套三级标题。
  - 多问共享数据时，可在模型章问题一之前设置一个公共数据处理二级标题；各问数据独立时分别写入对应问题；部分共享时采用公共处理与问题专属处理结合。
  - 检验独立成章(2023 A165、2021 A115、2022 A022/B086)或内嵌(其余);
  - 2025 C023 增加「AI 使用记录」章(2025 年新规范,2025 起建议保留);
  - 数据/输入说明按共享关系决定位置，不在问题分析之后、模型假设之前另起固定一级章；问题分析只概括处理计划，模型章写实际处理方法、参数和结果。
  - 2023 A175 省略「问题重述」直接进问题分析——少数派,不推荐;
  - **注意**:章节编号缺失、断裂和重复在语料中频繁出现(2020 B 章号二→四→五→六→七→九断裂、2021 B026 两个 6.1.1、2023 B311 两个 6.2)——这是普遍反模式,交付前必须逐章核对编号连续唯一。

## 2. 标准块要点

| 标准块 | 写法要点 | 语料证据 |
|---|---|---|
| 问题重述 | 1.1 问题背景 + 1.2 问题提出;背景写 2–3 句社会/工程意义,不要抄题目 | 27/28 采用(2023 A175 省略) |
| 问题分析 | 逐问一小节且每问至少独立成一个自然段，不得把多个问题合并进同一个大段；简单问写一个完整自然段，复杂问可分成多个逻辑连贯的自然段，但不机械增设三级标题；**不在开头写总结**，也不另设“各问之间的联系”等汇总小节；任务、数学类型、跨问依赖、数据条件、方法依据、验证和交付按叙事需要融入各问；框架图仅在确能澄清相关问题时按需插入对应问题小节 | 26/28 有独立分析章 |
| 模型假设 | **2–8 条**,编号列表,每条一句话;可接受的假设(如忽略空气阻力)要显式写出,不可接受的(如数据无误差)会被扣分 | 假设 2–7 条常见(2020 B 缺整章是反例) |
| 符号说明 | **表格**呈现:符号 | 含义 | 单位;放在建模前 | 全部采用表格 |
| 模型建立与求解 | 逐问成节,内部按「分析 → 建模 → 求解 → 结果」流水线(见建模 playbook) | 28/28 采用 |
| 模型评价与推广 | 优点 + 缺点(主动示弱)+ 改进/推广,每类 1–5 条 | 28/28 有评价;独立推广段约 14/28(非必须但加分) |

## 3. 子节命名风格

- 统一「x.y 描述」式:**章号.节号 + 短描述**,如「1.1 问题背景」「5.1 问题一模型的建立与求解」「5.1.1 相关概念的说明」。
- 按问题组织:模型章内以「5.1 问题一：任务内容 / 5.2 问题二：任务内容 / …」划分；每问内部标题按机理、数据、目标、约束、算法或结果的实际内容命名，不把所有模型堆在一节，也不机械复制“建模思路—模型建立—模型求解—结果分析—模型检验”。
- 算法/步骤可用「算法 1:…」「Step1–Step4」编号(2023 A165/A127 采用),增强可读性。

## 4. 篇幅基线(语料统计)

- 正文(不含附录代码)约 **1.2 万 – 2.6 万汉字**,对应 15–30 页;国赛官方正文上限通常 30 页,摘要不超过 1 页。
- 附录放代码和超长表格;正文只引用,不堆叠。附录代码占比过高(如 2021 A115 附录占全文 38%)会挤压正文篇幅,注意控制。
- 每道题的小问较多时(4–5 问),每问篇幅大致均衡,不要一问 10 页另一问 2 页。

## 5. 章节自检清单

- [ ] 八段骨架齐全?缺哪块(尤其「模型评价」)?
- [ ] 问题分析章每问都有对应段落/思路图?
- [ ] 模型假设 2–8 条、编号、单句?
- [ ] 符号说明是表格且含单位?
- [ ] 模型章按问题顺序组织，问题一前至多一个公共数据处理二级标题，内部标题按内容生成且论证闭环完整?
- [ ] 逐章核对章节编号连续唯一?
- [ ] 检验手段存在(独立章或内嵌)?
- [ ] 结尾有评价(优点/缺点/推广)?
- [ ] 附录含代码,正文引用了附录?
- [ ] 章节体量与内容匹配:数据/输入说明没有因内容少而硬凑大章节,也没有塞进问题重述?
