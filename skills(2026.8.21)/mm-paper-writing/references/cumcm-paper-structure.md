# 国赛（CUMCM）论文结构规范

> 本文件 = **官方硬性要求**（必须遵守）+ **获奖论文惯例**（加分项，来自 `corpus/` 语料 playbook）。
> 以当届官方通知为准；官方格式硬性要求见 `official-cumcm-format-2026.md`，原文 PDF 在 `official/` 目录。
> 本规范只服务 CUMCM 2026，不用于其他竞赛。

## 一、排版总要求（官方硬性）

- **不要目录**：论文不设目录，摘要后直接进入正文（官方明确要求）。
- **页边距**：上下左右**各至少 2.5 厘米**（官方下限，不得为写满摘要而缩小）。
- **页面顺序（纸质版）**：第 1 页承诺书 → 第 2 页编号专用页 → **第 3 页摘要专用页** → 第 4 页起正文 → 附录。**电子版第一页必须为摘要专用页**（不放承诺书/编号页）。
- **摘要页**：内容（含标题与关键词）原则上不超过一页；**页码从摘要页开始**，页脚中部，阿拉伯数字从 "1" 连续编号。
- **正文**：指摘要之后、附录之前的全部内容，包含正文顺序章节、必设的 AI 工具使用声明和参考文献；摘要与附录不属于正文。正文篇幅为 27--30 页，以当届官方规定为准；各章节连续自然排版，不因章节标题另起一页。
- **附录**：页数不限，含支撑材料文件列表与**全部完整、可运行的源程序**（见"附录"节）。
- **匿名**：摘要页、正文、附录任何位置不得出现参赛者身份、学校、赛区信息。
- **页眉**：官方未对页眉作统一规定；默认不设页眉（页脚只放页码），避免页眉出现校名、队号等身份信息。LaTeX 须显式 `\pagestyle{plain}`（ctexart 默认 headings 样式会在页眉自动放章节名和页码）。
- 官方对**字号、字体、行距、颜色不做统一要求**——美观可读是质量追求，不是硬性线。
- 流水线默认版式（非官方硬性）：无官方模板或用户覆盖时，主标题与摘要标题均为三号黑体；一级标题小三号黑体并居中，二级标题四号黑体，三级标题与正文小四号，图题表题小四号，表内文字五号；正文单倍行距，相邻正文段落额外间隔约四分之一行。关键词行位于可打印版心纵向 78%--90%。详细测量见 `abstract-writing.md`。
- **一级标题编号**：表示顺序的一级标题使用中文数字序号加顿号（如“一、问题重述”“二、问题分析”）；“参考文献”“附录”“AI 工具使用声明”等非顺序标题不加序号。二级、三级标题可用阿拉伯数字层级编号或无编号短标题，但必须全文统一。

## 二、章节骨架（获奖惯例八段式 + 官方要求）

获奖论文主链（28/28 篇一致）：**问题重述 → 问题分析 → 模型假设 → 符号说明 → 分问建模与求解 → 模型评价与推广 → 参考文献 → 附录**。

```text
一、问题重述（1.1 问题背景 / 1.2 问题提出）
二、问题分析（逐问分析，常附总体思路图 / 技术路线图）
三、模型假设（2–8 条，编号列表）
四、符号说明（表格：符号 | 含义 | 单位）
五、模型的建立与求解（逐问成节：5.1 问题一 … 5.4 问题四）
   └ 也可逐问独立成章：「五、问题一的模型建立与求解」「六、问题二的模型建立与求解」…（两种结构均常见，见 corpus/章节组织-playbook.md）
└ 每问内嵌：承接分析（1~3 句，不设"建模思路"小节）→ 建模 → 求解 → 结果表 → 结果分析 → 检验；小节标题随问拟定、四问不得雷同
六、模型对比（可独立成节/章，或内嵌于对应问）
七、灵敏度分析与鲁棒性分析（可独立成章，或内嵌于结果分析）
八、模型评价与推广（优点 + 缺点（示弱）+ 改进/推广）
九、参考文献（此处仅为结构示意；正式论文中“参考文献”不加顺序序号）
附录（代码 / 支撑材料文件列表；正式论文中“附录”不加顺序序号）
```

各章要点：

1. **摘要**（摘要专用页，写满一页但不超过一页；量化规则见 `abstract-writing.md` 与 `corpus/摘要写作-playbook.md`）
2. **问题重述**：1.1 问题背景（2–3 句意义）+ 1.2 问题提出；用自己的话，不抄原题。
3. **问题分析**：逐问一小节，标题固定为「问题X的分析」；逐问段落先定性再定量，末尾给求解思路或技术路线。问题分析不展开数据清洗、特征构造和描述统计；重要的数据预处理独立成章，否则并入对应模型部分。
4. **模型假设**：2–8 条编号列表，每条一句话，说明理由；可接受的简化要显式写出。
5. **符号说明**：表格放在建模前，**默认只保留两列（符号 | 含义）**；单位与取值范围在正文公式处给出即可，不单独成列，避免表格臃肿。
6. **模型建立与求解**（核心）：逐问成节，每问内部按「承接分析→建模→求解说明→结果表→结果分析」展开；每问至少有一张结果表。成熟方法用连续段落或普通编号说明，编号形式不固定；只有复杂自研算法才允许算法流程图。小节标题按题型现场拟定；四问合章时保留「——问题X」后缀，分章时用「问题X的模型建立与求解」。
7. **模型对比**：备选模型 vs 所选模型，同数据同指标，证明所选更优（可独立成节或内嵌）。
8. **验证证据**：模型对比、检验、灵敏度和鲁棒性按题目需要选择，可独立成章或内嵌；凡声称更优、稳定或可靠，必须提供对应证据。
9. **模型评价与推广**：优点（1–5 条）+ **缺点（主动示弱，承认至少一个局限）** + 改进/推广（具体场景）。
10. **参考文献**：按引用顺序编号；正文引用处标注；建议 8 条以上。无用户或题目特殊要求时，中文权威文献原则上不少于 60%，并明显多于外文文献。中文标准、政府/行业资料、权威教材和直接相关的中文期刊论文优先；原始方法、国际标准和国内没有可靠替代的关键研究保留外文。只列正文实际引用且可核验的来源，不为凑中文比例引二手、低质量或无关资料，也不编造文献。
11. **附录**：以"附录"为标题，列出支撑材料完整文件清单并附全部完整、可运行的源程序；紧凑排版不得省略必要源码。
12. **章节体量与内容匹配**：内容撑不起时不要独立成章；数据、地图和参数来源放在最相关的位置，不硬凑章节。

## 三、图表数量与格式（获奖惯例）

- **数量基线**：正文**图 ≥ 8 张、表 ≥ 5 张**；每个子问题至少 1 个有信息量的图和 1 个有信息量的表，图表类型按题目证据选择，不强制每问都制作数据图。机理/几何题和数据题按实际信息增益安排图表。
- 图题「图 N 描述」（图下方），表题「表 N 描述」（表上方）；**全文连续编号，无重号/跳号**；正文必须引用每张图/表。
- **三线表**：结果表、参数表、符号表一律三线表（顶线/栏目线/底线，无竖线）。
- 图内文字可读，位图 ≥ 300 DPI；子图用 (a)(b) 标注。
- 详见 `corpus/图表规范-playbook.md`。
- **图量按证据需要确定**：不按预设页数上调图件数量；每张图必须有明确叙事作用，禁止为凑图而堆图。

## 四、常见注意

- 摘要质量极大影响获奖，单独精雕（字数 550–1100、逐问分块、每问带数字）。
- **正文篇幅**：默认 27--30 页，以当届官方规定为准；重点放在模型建立、真实结果和解释。模型对比、检验、灵敏度与鲁棒性仅在适用时占篇幅；不得注水。
- **排版留白控制**：默认 `[htbp]`，一级和二级标题边界均使用 `\FloatBarrier`；通过尺寸、插入位置和间距处理留白，关键图表才使用 `[H]`。
- **表格字号与对齐**：表内文字统一五号（10.5pt），表头、文字与数字水平居中；长文本单元格使用居中的定宽列换行，避免 overfull。
- **图表浮动**：默认 `[htbp]`，每个二级标题前用 `\FloatBarrier` 清空上一小节浮动体；只有必须锁定在解释段后的关键表才使用 `[H]`。
- **关键表顺序**：数据审计表、符号表和核心结果汇总表紧跟首次引出，并优先于同节大型图片。若编译后关键表被图片挤到下一页或形成孤立浮动页，先重排源码锚点，再仅对该表使用 `[H]`。
- **求解步骤的呈现**：成熟求解器不设"求解方法/求解流程"小节，只在模型小节末尾用一两句"模型性质→工具→关键参数→结果"带过；自研算法用行文编号简要交代，嵌入模型小节或并入结果小节；每问结果小节标题随问拟定，不共用"结果与分析"。
- 公式连续编号并在正文交叉引用；求解说明根据内容使用连续段落或普通编号，编号形式与全文协调；复杂自研算法可配置流程图。
- **数字三处一致**：摘要 / 表内 / 正文的数字必须完全一致，精度统一（2–3 位小数）。
- 数据真实：论文数字与 `results/` 一致，不编造；不出现"本题/本团队"之外的模糊表述。
- 语言客观、量化；措辞规范见 `corpus/语言与措辞-playbook.md`，易错点见 `corpus/易错点与反模式-playbook.md`。
