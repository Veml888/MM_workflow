# 章节组织 playbook

> **定位：语料证据**（章节骨架统计与反例），不是操作规范；章节结构、篇幅与各块写法以 `references/cumcm-paper-structure.md` 为准，冲突时以操作规范为准。

> 基于 28 篇国赛优秀论文语料(2020–2025)统计。2023 语料 12/13 篇可读篇目与 15 篇 OCR 篇目全部采用同一骨架。

## 1. 顶层章节骨架(八段式,跨 6 年 28/28 篇主链一致)

```
一、问题重述(1.1 问题背景 / 1.2 问题提出)
二、问题分析(逐问分析,常附总体思路图)
三、模型假设(2–8 条,编号列表)
四、符号说明(表格)
五、模型的建立与求解(逐问成节:5.1 问题一 … 5.4 问题四)
六、模型的评价与推广(或「模型评价与改进」)
七、参考文献
附录(代码 / 支撑材料)
```

- **别自创大框架**:28/28 篇主链一致(重述→分析→假设→符号→分问建模求解→评价→参考文献→附录)。常见微调(均属正常):
  - **分问建模的两种章节组织(均常见,按题/篇幅选择)**:
    - **整体成章**(最主流):「五、模型的建立与求解」章内按「5.1 问题一 / 5.2 问题二 / …」分节,每节内「分析 → 建模 → 求解 → 结果」流水线;
    - **逐问独立成章**:「五、问题一的模型建立与求解」「六、问题二的模型建立与求解」「七、问题三的模型建立与求解」……每问一个一级章,评价/推广章统一放在最后。此结构适合问题之间独立性较强或每问模型差异较大的题目,便于评阅按问定位。
  - 数据/统计类题目加独立「数据预处理/数据侧写」章(2021 B026、2024 C234、2025 A196 的「模型准备」、2023 C050);
  - 检验独立成章(2023 A165、2021 A115、2022 A022/B086)或内嵌(其余);
  - 2025 C023 增加「AI 使用记录」章(2025 年新规范,2025 起建议保留);
  - 数据/输入说明按**体量**决定层级:内容少并入模型假设或参数表说明;内容多且有独立价值才设「数据与地图」章(放问题分析之后、模型假设之前),不硬凑大章节;
  - 2023 A175 省略「问题重述」直接进问题分析——少数派,不推荐;
  - **注意**:章节编号缺失/断裂/重复在语料中频繁出现(2020 B 章号二→四→五→六→七→九断裂、2021 B026 两个 6.1.1、2023 B311 两个 6.2)——这是普遍反模式,交付前必须逐章核对编号连续唯一;逐问独立成章时尤其注意章号连续(五、六、七…)。

## 2. 标准块要点

| 标准块 | 写法要点 | 语料证据 |
|---|---|---|
| 问题重述 | 1.1 问题背景 + 1.2 问题提出;背景写 2–3 句社会/工程意义,不要抄题目 | 27/28 采用(2023 A175 省略) |
| 问题分析 | 逐问一段,先定性再定量,末尾给「求解思路/技术路线」;**不在开头写总结**;如需总结,放在逐问分析之后的独立小节(各问联系紧密时再写);可附总体思路图 | 26/28 有独立分析章 |
| 模型假设 | **2–8 条**,编号列表,每条一句话;可接受的假设(如忽略空气阻力)要显式写出,不可接受的(如数据无误差)会被扣分 | 假设 2–7 条常见(2020 B 缺整章是反例) |
| 符号说明 | **表格**呈现:符号 | 含义 | 单位;放在建模前 | 全部采用表格 |
| 模型建立与求解 | 逐问成节,内部按「分析 → 建模 → 求解 → 结果」流水线(见建模 playbook) | 28/28 采用 |
| 模型评价与推广 | 优点 + 缺点(主动示弱)+ 改进/推广,每类 1–5 条 | 28/28 有评价;独立推广段约 14/28(非必须但加分) |

## 3. 子节命名风格

- 统一「x.y 描述」式:**章号.节号 + 短描述**,如「1.1 问题背景」「5.1 问题一模型的建立与求解」「5.1.1 相关概念的说明」。
- 按问题组织:整体成章时模型章内以「5.1 问题一 / 5.2 问题二 / …」划分;逐问独立成章时章题用「问题X的模型建立与求解」(如「五、问题一的模型建立与求解」)。两种都不应把所有模型堆在一节。
- 算法/步骤可用「算法 1:…」「Step1–Step4」编号(2023 A165/A127 采用),增强可读性。

## 4. 篇幅基线(语料统计)

- 正文(不含附录代码)约 **1.2 万 – 2.6 万汉字**,对应 15–30 页;国赛官方正文上限通常 30 页,摘要不超过 1 页。
- 附录放代码和超长表格;正文只引用,不堆叠。附录代码占比过高(如 2021 A115 附录占全文 38%)会挤压正文篇幅,注意控制。
- 每道题的小问较多时(4–5 问),每问篇幅大致均衡,不要一问 10 页另一问 2 页。

## 5. 章节自检清单

- [ ] 八段骨架齐全?缺哪块(尤其「模型评价」)?
- [ ] 问题分析章每问都有对应段落/思路图?
- [ ] 模型假设 2–8 条、编号、单句?
- [ ] 符号说明是表格且含单位?
- [ ] 分问建模按问题组织(整体成章「5.1/5.2/5.3」或逐问独立成章「问题X的模型建立与求解」),内部流水线完整?
- [ ] 逐章核对章节编号连续唯一(整体/独立成章都要)?
- [ ] 检验手段存在(独立章或内嵌)?
- [ ] 结尾有评价(优点/缺点/推广)?
- [ ] 附录含代码,正文引用了附录?
- [ ] 章节体量与内容匹配:数据/输入说明没有因内容少而硬凑大章节,也没有塞进问题重述?
