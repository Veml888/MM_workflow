# 数据审计手册（有样本型、时序型或实验记录型表格时必读）

触发条件：题面附件按样本、时间或实验记录组织成 XLSX/CSV 等表格；不要求必须预先划分训练集和测试集。纯参数表、规则表跳过样本级统计审计，但仍执行单位、范围、来源和一致性检查。

审计结论全部写入 `docs/01-analysis-report.md`，并冻结为后续建模的字段集合。

## 1. 必审清单

1. 样本量、字段类型；分类任务另查类别数量与比例；
2. 缺失值、异常值、常量和重复列；
3. 身份编码、机构编码和高基数类别；
4. 日期重复信息与可能泄漏标签的字段；
5. 总计字段与分项字段的逐条闭合关系；
6. 精确派生字段的公式、方向和单位；
7. 比例字段的分子、分母、零分母和哨兵值；
8. 存在训练/测试、前后时段或批次分组时，比较字段类型、取值范围和分布偏移。

## 2. 五张必出审计表

### 表 1：数据概况

| 字段 | 类型 | 量纲/单位 | 缺失率 | 异常值 | 常量/重复列 | 备注 |
|---|---|---|---|---|---|---|

### 表 2：字段关系审计（闭合与派生）

逐条复算总计=分项、派生字段公式，记录公式、方向、单位和闭合误差。**相关系数不能代替账务等式检查；高相关不等于字段闭合。**

### 表 3：比例公式审计

分子、分母、零分母处理、哨兵值（-999/9999/空）、比例是否超界、单位换算。

### 表 4：标识符审计

ID 是否唯一、是否包含目标信息、是否进入特征（**身份编码不得因训练表现好就进评分器**）、训练/测试 ID 交集与泄漏风险。

### 表 5：分布偏移

| 字段 | 训练类型/范围 | 测试类型/范围 | PSI | 闭合率 | 哨兵异常 | 处置 |
|---|---|---|---|---|---|---|

PSI 仅在两个可比样本组都具有足够样本时使用；`> 0.1` 只能作为偏移提示，不是自动剔除阈值。小样本优先报告范围、分位数、类别支持集和不确定性。偏移审计只作诊断，**不得利用最终测试集反向修改字段或模型**。

## 3. 字段保留/剔除决策

每个字段给出：字段定义 → 逐条复算或仅基于训练折的证据 → 动作（保留 / 剔除 / 变换）。没有证据的字段不得直接进入候选特征；题面明确要求保留的字段应标记为“仅输出/约束用途”，不得静默删除。

## 4. 边界

- 训练数据负责字段选择、标准化、变量筛选、技术阈值和决策参数；无官方划分时，只提出后续划分策略，不在本阶段反复试验划分结果。
- 最终评价数据只在全部规则冻结后用于一次性外部评价；不得通过图表、汇总统计或人工挑选间接泄漏标签。
- 本阶段可运行只读的数据剖析与校验工具并保存证据，但不训练模型、不调参、不运行求解器；任何临时分析不得改写 `data/`。
