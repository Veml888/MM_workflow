# 数学建模竞赛论文流程图

创建能够承担论证功能的学术图。目标是国家级竞赛优秀论文的清晰度、严谨性和版面完成度，但不承诺任何奖项结果。

跨阶段通用规则以 `../mm-orchestrator/references/cumcm-2026-shared-policy.md` 为准；读取 `paper/figure-requirements.md`，并按 `../mm-orchestrator/references/project-manifest-contract.md` 登记图件 ID、正文锚点、哈希和版本。

## 输入与产出

读取存在的题面、`docs/01-analysis-report.md`、`docs/02-modeling-report.md`、`docs/03-results-report.md`、`paper/structure-draft.md`、`paper/figure-requirements.md`，以及 `figures/` 清单。只读取当前图需要的内容。

默认交付：

- `figures/<descriptive-name>.tex`：可编辑 TikZ 源；
- `figures/<descriptive-name>.pdf`：XeLaTeX 编译的矢量终稿；
- `figures/<descriptive-name>_600dpi.png`：按论文物理宽度渲染的位图备份；
- `docs/05-diagrams-report.md`：记录论证用途、正文位置、逻辑骨架、候选布局、选择依据、审查指标和视觉验收。

只有用户或下游明确要求 SVG、网页嵌入或 SVG 语义审计时，才附 `.svg` 并运行 SVG 分支。用户明确要求 draw.io 时再附 `.drawio`。Mermaid 只可验证拓扑，不作为论文成图。

## 论文风格硬约束

1. **拒绝 PPT 风**：禁止阴影、渐变、玻璃效果、浮动卡片、胶囊标签、装饰图标、大面积彩色底板、营销式大标题和口号式副标题。
2. **图题外置**：论文版默认不在画布内重复大标题或副标题；使用 LaTeX `\caption`。画布只保留必要的分区标题、节点、边标签和图例。
3. **中文优先**：中文论文的节点、分支和旁注使用中文；仅保留必要变量、公式和标准缩写。
4. **框架与逻辑优先**：普通节点统一使用矩形，圆角矩形只表示起止或状态，菱形只表示真正的判断。输入、处理、模型与输出依靠所处层级、分区标题、节点文字和箭头关系区分，不使用平行四边形等异形节点增加视觉噪声。
5. **拓扑优先**：保持单一阅读方向；反馈沿外围返回；箭头不得穿过节点，交叉边应为 0，确实不可避免时先重排或拆图。
6. **文字克制**：节点使用 4–12 个汉字的名词或动宾短语，最多两行；解释放正文，边标签只说明关系或条件。
7. **物理尺寸验收**：按最终嵌入宽度计算字号和线宽。正文标签不得小于 8 pt，推荐 8.5–10 pt；PDF 自然宽度应接近最终嵌入宽度，避免靠大比例缩放补救排版。
8. **少色且可灰度打印**：默认黑、深灰和一种低饱和强调色；最多 3 个语义色。颜色必须有含义，并同时用位置、边框或线型冗余编码。
9. **全篇一致**：同一论文的字体、节点圆角、边框、箭头、色彩和图题写法使用统一设计令牌。
10. **命名规范**：文件名和 `\caption` 不使用“问题一/二/三、Q1/Q2”等题号，用内容与场景命名。

详细设计规则与量化评分见 [references/flow-design-playbook.md](references/flow-design-playbook.md)。

## 工作流

### 1. 建立 DIAGRAM PLAN

写明每张图的一个核心论证目标、来源依据、图类型、拟放正文位置和与已有图的区别。没有信息增益的孤图不要制作。

### 2. 抽取语义图

先列出节点、节点类型、边、边标签、主链、反馈、分组和外部约束。消除逻辑歧义后再绘图；不得自行补造模型步骤。

### 3. 生成两个布局骨架并择优

为同一语义图至少提出两个可行布局，例如纵向主链与横向阶段、分层与泳道、中心机制与左右输入输出。仅画低成本骨架，按以下指标比较：

- 交叉边数量；
- 总转折数与最长反馈线；
- 主链阅读距离；
- 节点密度和外部留白；
- 最终物理字号；
- 与正文版心的纵横比匹配。

输出 `LAYOUT DECISION: <选定布局> — <比较依据>`。不能只因为示例文件存在就选该布局。

### 4. 计算几何并生成 TikZ

- 先确定最终宽度：单栏约 8–9 cm，通栏通常 13.5–15 cm；再反推字号、节点尺寸和间距。
- 使用 `standalone` + `fontspec` + TikZ，由 XeLaTeX 排版中文；详细实现规则见 [references/tikz-guide.md](references/tikz-guide.md)。
- 节点使用内容自适应尺寸、`inner xsep/inner ysep` 和必要的 `minimum width/height`；不得手算字符坐标，不得用固定框硬塞文字。
- 相对位置必须基于节点边界锚点。对多个输入的中点先取边界坐标，再用 `anchor=west/east` 和 `xshift/yshift` 留出净距；不得把 `right=... of <零尺寸 coordinate>` 误当成两个方框之间的净距。
- 主边优先使用正交线；每条边最多两个转折；多个同向连接优先采用对齐端口或公共母线。
- 用外围轨道绘制反馈，不绕过半张画布制造无效长线。
- 不在画布中写论文图题；分区标题与节点建立清楚但克制的层级。
- 普通处理节点仅轻微圆角或直角；明显圆角只用于起止/状态，菱形只用于真实判断。
- 从 [examples/paper-evidence-chain.tex](examples/paper-evidence-chain.tex) 复用设计令牌与边界锚点模式，但按当前语义图重新布局，不照抄节点。

### 5. 执行自动审查与渲染

确认本机有 MiKTeX/TeX Live 的 `xelatex` 与 `pdftocairo`，再运行：

```powershell
python scripts/render_tikz.py figures/fig_xxx.tex `
  --png figures/fig_xxx_600dpi.png --dpi 600 --strict
```

脚本必须成功生成同名 PDF 与带 DPI 元数据的 PNG。检查 `.log` 中无 LaTeX Error、缺字、未定义控制序列和 `Overfull \hbox`。

如果明确走 SVG 兼容分支，再运行 `scripts/audit_svg.py` 与 `scripts/render_svg.py`；SVG 不再是默认论文源。

自动编译通过不等于视觉通过。必须回读最终 PNG，检查文字是否全部在框内、节点是否重叠、箭头是否从正确方向进入、线路是否穿框、边标签是否碰线、反馈是否走外轨、是否存在无语义线条，并按实际论文缩放检查字号、空白和灰度效果。任何一项失败都要修订、重新编译并再次回读；不得把有缺陷的首版交给用户。

### 6. 论文级验收

使用 playbook 的 100 分量表；总分至少 90，逻辑准确与论文风格两项不得失分至否决线，且无任何一票否决项。报告具体分数和证据，不允许无依据写 `visual_review: passed`。

### 7. 交付与嵌入

报告稳定 ID、TEX/PDF/PNG 路径、像素尺寸、DPI、PDF 自然尺寸、最终嵌入宽度、正文锚点、建议 `\caption`、候选布局比较和审查结果，并同步更新 `project-manifest.json`。本 skill 不修改 `paper/论文.tex`；论文终稿由 `mm-paper-writing` 插入 PDF，并在真实版心中再次编译检查。

## 边界

- 不绘制成熟求解器、常规算法或一般求解步骤。复杂自研算法若确有实质分支、循环、状态更新或终止机制，可绘制算法流程图。
- 不绘制数据图，不重跑模型，不修改数值结论。
- 不用 imagegen 生成包含精确中文节点与箭头的流程图。
- 用户明确要求答辩版时，可另做高对比版本，但必须同时保留克制的论文版。
