# 案例卡（case-cards）

**只做"判型+主线模型"示范**，用于反哺分析深度；具体公式以当届数据为准。

与 `model-selection-library.md` 的关系：library 是"场景→候选"的检索表，本文件是"真题怎么拆"的启发素材。两者配合使用，先查库、再翻案例。

## 1. 2021B 乙醇偶合制备 C4 烯烃

- 主线：实验设计审计（温度/催化剂组合、天然对照）→ 机理-经验式（Arrhenius 型温度效应、S 型响应）→ 响应面（催化剂组合）→ 优化工艺条件。
- 高分点：推导链完整 + 响应面各项来源可解释 + 最优区外推边界说清。

## 2. 2021C 原材料订购与运输

- 主线：供应商评价（熵权/TOPSIS）→ 0-1 订购优化 + 运输最小费用流。
- 高分点：评价-优化接口清晰、转运方案可行。

## 3. 2020A 炉温曲线

- 主线：一维/二维热传导 PDE → 参数辨识（与数据对照）→ 传送带速度优化。
- 高分点：参数辨识给置信区间、数值稳定性说明。

## 4. 2023A 定日镜场

- 主线：几何光学（余弦损失/遮挡）→ 大规模优化（网格+启发式）。
- 高分点：目标函数逐项物理来源、规模-算法复杂度匹配。

## 5. 2023B 多波束测线

- 主线：几何覆盖 → 测线间距优化（重叠率约束）。
- 高分点：先证明几何公式再优化，避免纯数值搜索。

## 6. 2022C 玻璃成分鉴别

- 主线：成分关联分析 + 分类/聚类 → 判别规则。
- 高分点：特征选择依据（文物/风化分组）、类别不平衡处理。

## 7. 2011B 交巡警平台

- 主线：网络建模（最短路径/覆盖）→ 指派/整数规划 → 调度方案。
- 高分点：节点/边定义清晰、工作量均衡作为第二目标。

## 8. 2017B 任务定价

- 主线：任务点聚类 → 定价回归 → 平台-接单人策略分析。
- 高分点：把"价格-完成率"关系建模后再优化，而不是直接给价。

## 使用约束

1. **真题锚点只用于启发判型与主线，不复制结论**，公式与结果必须由本赛题数据重新建立与核验。
2. 案例卡的"主线"映射到 `problem-taxonomy.md` 的判型组合 + `model-selection-library.md` 的场景；不允许把"主线"作为最终结论直接搬用。
3. 案例卡出现"具体公式以当届数据为准"时，分析阶段必须重新推导，不得直接套用历年同题号的公式与参数。
