# 赛题阅读协定（problem-reading-protocol）

用于在正式问题分析前**冻结、复现和核验** CUMCM 赛题；不进行题型判断、模型选择、参数设定、编码或求解。在 SKILL.md 的工作流中由 **Step 0 阶段 GATE 与只读盘点** 引用；执行时按本文件全文操作。

## 0. 复现稿 vs 问题重述（必先分清）

- **复现稿**：`docs/00-problem-transcription.md`，按页复现原始题面、附件关系、图表位置——**只复现、不解释、不发挥**。
- **语义解释稿**：`docs/00-problem-interpretation.md`，按子问题做 G-SEM 语义核对——**忠实解释题意、记录歧义与口径**。
- **问题重述**：写到 `docs/01-analysis-report.md` 的 §1，用自己的话把题目背景、任务目标、要回答的问题再讲一遍——**这是分析阶段的产物**，由 Step 1 产出。

复现稿与语义解释稿在 Step 0 完成；问题重述在 Step 1 完成。两者不得混在一起，复现稿不得混入分析、模型解释或推测。

## 1. 产物位置

每道题在项目内保存：

```text
docs/00-problem-transcription.md
docs/00-problem-interpretation.md
docs/source-evidence/       # 仅在需要时建立
├── formulas/
├── figures/
└── tables/
```

`data/` 中的官方 PDF、图片和附件保持只读。复现稿按原始 PDF 页序保存题面文字、问题、注释、附件说明和有信息价值的图表位置；不把分析、模型解释或推测混入复现稿。

## 2. 读取顺序

1. 核对题面是否完整、附件是否齐全、文件是否可打开，并记录文件路径、格式和 SHA256。
2. 优先读取可靠的 PDF 原生文本层；只有文本层缺失或不可靠时才使用 OCR 或视觉读取。
3. 按页复现题面到 `docs/00-problem-transcription.md`，保留原题标题、层级、问题编号、限制条件、图题、表题、脚注和附件关系。
4. 对公式、上下标、希腊字母、符号、小数点、单位、表头、合并单元格和图中标注进行视觉复核。
5. 对有结构价值的原题图、公式和复杂表格保存裁剪证据到 `docs/source-evidence/`，并在复现稿中记录页码、位置和稳定 ID。
6. 完成来源核对后，才进入分析阶段的问题重述和数据审计。

## 3. 题意语义核对（G-SEM）

文字复现正确不等于题意解释正确。对每个子问题建立 `docs/00-problem-interpretation.md`，至少填写：

| 字段 | 要回答的问题 |
|---|---|
| 题面位置 | 原题第几页、哪一段或哪一表 |
| 动作 | 题目要求分析、比较、预测、分类、优化、设计还是解释什么 |
| 对象 | 研究哪些样本、变量、类别、时间段或空间范围 |
| 输入 | 允许使用哪些题面数据和附件字段 |
| 输出 | 必须交付数值、规则、图表、方案、区间还是建议 |
| 范围与量词 | 适用对象、至少/至多、必须/可以、是否分类型或分阶段 |
| 明确不推出 | 题面没有要求或数据不能支持的因果、外推和评价 |
| 依赖关系 | 是否依赖其他子问题的结果，哪些结果只能后置使用 |
| 解释分歧 | 可能的另一种读法及排除它的原题证据 |
| 图证口径 | 题面图对该问关键量的几何定义与方向约定（口径画在哪条线段/哪个角之间、法向或参考方向的朝向、正负号约定）；图文不一致时记录并回看原题 |

**方向与口径登记表（G-SEM 必填工件，凡带方向/口径约定的量逐行登记）**：空行或未结论即 G-SEM 不通过。模板：

| 量与约定 | 口径/朝向依据（题面图哪个箭头或哪句话） | 反向约定结果 | 镜像/歧义判定 |
|---|---|---|---|

每个子问题先由题面原句形成一行忠实解释，再用独立的一遍复现稿检查：解释是否把"分析"偷换成"证明"，把"预测"偷换成"优化"，把建议性内容写成硬约束，或把某问的限制条件错误套到另一问。出现分歧时回看原题并记录，不得用模型常识自行裁决。

**G-SEM 通过条件**：每个 `P-##` 均有上述字段；动作、对象、输入、输出和限制能回到原题位置；不存在未解决的语义分歧；"明确不推出"和适用边界已写出；关键量的图证口径与方向约定已从题面图提取并登记。未通过时，只允许继续做来源核验，不得进入模型候选筛选。

## 4. 稳定 ID 与追溯

按需使用以下 ID：`SRC-###`（原始文件）、`FIG-###`（题面图）、`TAB-###`（题面表）、`EQ-###`（公式）、`DS-###`（数据文件）。每个 ID 记录原题页码、位置和文件路径。

普通无信息装饰图不强制裁剪；承载空间关系、曲线、坐标或网络信息的图必须保留原始视觉证据。能够可靠结构化的题面表格可同时保存机器可读副本，但不得覆盖原始附件，派生文件必须与 `data/` 分开。

## 5. 高风险内容与阻断规则

以下内容不得仅依赖 OCR 或普通文本提取：公式、上下标、正负号、不等号、小数点、百分号、单位、表头、脚注、图内标注及容易混淆的数字字母。

若关键内容无法确认，必须：

1. 在复现稿中标记"待确认"，记录页码、位置和疑点；
2. 保留视觉证据；
3. **阻断依赖该内容的子问题**——本子问题不得进入 Step 1/2/3 实质分析。

非关键的版面或装饰疑点可以登记后继续，不得把局部疑点扩大为整题阻断。禁止猜测、脑补、补全公式或将模型解释写成题面要求。

## 6. 双向核对门禁（G-READ）

执行两次互补检查：

- **正向**：`原始题面 → docs/00-problem-transcription.md`，检查是否遗漏文字、数字、单位、限制、图、表和附件关系。
- **反向**：`docs/00-problem-transcription.md → 原始题面`，检查复现稿每项是否能回到真实页码和位置，排除 OCR 幻觉、错转录和自行补充。

对公式、关键数字、硬性约束和附件字段，复现稿必须能回答"来自哪一页、哪一处、哪个原始文件"。两次检查后的修正应再抽查关键项，避免修复引入偏移；不要求在竞赛时间内机械重复三次全量抄录。

## 7. 通过条件（G-READ=PASS）

满足以下全部条件后，将 `G-READ=PASS` 写入分析阶段记录：

1. 原始题面和官方附件可访问且未缺页；
2. `docs/00-problem-transcription.md` 已生成并按页复现；
3. 公式、关键数字、单位、表头、硬约束和附件关系已完成视觉或来源核验；
4. 关键图表有稳定 ID 和必要的证据路径；
5. 正向与反向核对完成；
6. 没有未处理的关键"待确认"项；
7. 每个子问题的 `G-SEM` 语义解释表已完成，且没有未解决的解释分歧。

**`G-READ` 或 `G-SEM` 未通过时，只输出缺口和阻断范围，不凭未经核验的 OCR、转录或模型记忆开展问题分析、建模、编码、绘图或论文写作。**

## 8. 与 quality-gates 的对应

`G-PA1~4`（阶段开工前 GATE）在本协议中通过 §2 读取顺序与 §1 产物位置落实；`G-READ` 与 `G-SEM` 是**题面复现门禁**，独立于 G-PA。完整登记见 `references/quality-gates.md`。
