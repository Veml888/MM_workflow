# 选图标准与图种库（mm-figures 数据图）

本文件是 mm-figures 的**选图决策参考**，供 Step 1「决定画哪些数据图」时查对：哪些结果值得画、画什么图种与维度、服务哪条结论。**何时合并成组合图、何时拆开**见 mm-figures SKILL 主线的「组合图判定」小节（那是 Step 1 的决策入口）；这里只回答"单张图选什么图种"。组合图里每个面板仍按本文件选图种，只是被编排进同一张图中。

## 一、选图标准

原则：**一图一结论**，图服务于论文论点。选图看三点，优先级从高到低：

1. **数据适配**——最能反映本数据结构与结论的图种（能直观呈现数据特征的优先）。
2. **表达力**——一眼看懂、信息密度高（一图就能定位"结论在哪、依据是什么"）。
3. **眼前一亮**——在常规图上做精细化与组合创新（**子图/组合图**、双轴、误差带、注释、配色映射、多帧），但不为炫技牺牲可读性与准确性。

不要整篇只有柱状图 + 折线图，也不要为凑图种硬上不合适的图。**合并成组合图与否**见 SKILL 主线「组合图判定」；本文件只回答"单张图选什么图种"。

### 基础图种数量约束（硬性：普通基础图种 ≤ 2）

- **何为"普通基础图种"**：柱状图（竖/横/分组）、折线图、散点图、饼图/环形图、雷达图、直方图这类**标准展示型图种**（对应 §二 常规图种表中"常规"部分，不含时序/空间/误差补充项和 §三 创新/进阶项）。
- **硬性上限**：整篇论文（或**每个子问题**）中，普通基础图种的**合计使用种类最多 2 种**。例：用了柱状图与折线图，就**不该再单独用散点图/雷达图/饼图**作为独立图。
- **超过怎么办**：同一论证需要的更多展示，改用**组合图（多面板，把多种展示合到一张图）**或**创新/进阶图种**（子图、双轴、误差带、3D、等高线、热力、帕累托、瀑布、桑基等）来承载——不是再加一张基础图去堆。
- **例外**：某一基础图种承载的是**跨子问题**的同一结论锚点、或该题确实只能用它表达（如纯占比用饼图），可记入 `figure-requirements.md` 说明理由，但单子问题内仍不超过 2 种基础图。
- 目的：**避免全篇被柱状图 + 折线图统治、沦为模板化**，逼出更贴合数据的图种与组合创新。

### 题型 → 必画图种（Step 1 决定画什么时按着查，避免漏画该题的诊断/支撑图）

> 下表按**题目类型**列出该类必须画（或强烈建议画）的图种，不只是"主结果图"，还包括**模型检验、收敛/诊断、不确定性**等支撑图。别只画主图而漏掉这些证明"模型可靠"的图。

| 题目类型 | 必画/建议的图种 | 所在表 |
|---|---|---|
| 预测/回归类 | 预测 vs 实际（+误差带）、残差诊断（残差 vs 拟合、Q-Q 图）、特征重要性 | 常规/统计诊断 |
| 分类/审核类 | ROC/AUC 曲线、Lift/容量捕获曲线、混淆矩阵热力图、分类概率分布 | 统计诊断 |
| **贝叶斯/MCMC 推断** | **MCMC 轨迹图、后验核密度图、自相关图（ACF）** | 统计诊断 |
| 时序预测 | 时间序列分解（趋势+季节+残差）、ACF/PACF、预测 vs 实际 | 时序 |
| 优化/选址/调度 | 收敛曲线（目标值 vs 迭代）、方案帕累托前沿、参数灵敏度、成本构成（瀑布） | 常规/创新 |
| 空间/位置/物流 | 空间分布图（对象着色标量场 / 等值线 / 地图落点）、距离衰减曲线 | 空间 |
| 多目标权衡 | 帕累托前沿（2D/3D）、平行坐标图、雷达图 | 创新 |

**统计诊断类图典型用于"证明模型可靠"**，凡采用统计检验、贝叶斯抽样、分类评估、回归诊断的题，除主结果图外务必补这类支撑图（它们最能体现"模型检验"的证据链）。

## 二、常规图种

| 数据/目的 | 推荐图 | 说明 |
|---|---|---|
| 随时间变化趋势 | 折线图 / 堆叠面积图 | 多系列区分线型/颜色 |
| 分类之间比较 | 柱状图（竖直/水平/分组） | 分组柱状做多系列对比 |
| 占比构成 | 饼图 / 环形图 / 堆叠柱状 | 类别少用饼图，含趋势用堆叠 |
| 两个连续变量关系 | 散点图（+拟合线+置信带） | 标注相关系数 |
| 分布形态 | 直方图 / 箱线图 / 小提琴图 | 箱线图适合多组分布对比 |
| 相关性矩阵 | 热力图 | 标注数值，发散色 |
| 多指标综合比较 | 雷达图 | 指标 5~9 个 |
| 参数影响/鲁棒性 | 灵敏度曲线（折线+误差棒） | 横轴参数、纵轴目标 |
| 预测 vs 实际 | 双线对比 + 误差带 | 强调拟合/预测效果 |
| 收敛过程 | 迭代次数-目标值曲线 | 智能优化/迭代算法必备 |

### 常规图种·补充（时序 / 空间 / 误差不确定性）

| 数据/目的 | 推荐图 | 说明 |
|---|---|---|
| 时间序列趋势+季节 | 时序分解（趋势+季节+残差三子图） | 拆解长期趋势/周期性/噪声 |
| 时序自相关 | ACF / PACF 自相关图 | 判断时间序列的记忆性/阶数 |
| 空间点分布 | 地图散点图 / 地图热力图（真实经纬度） | 标注真实站点/落点，用 basemap/geopandas |
| **对象着色标量场**（场坐标分布图） | 散点颜色映射（x,y 坐标 + 第三维标量→colorbar） | 每个离散对象（定日镜/站点/格点）一个彩点，颜色编码效率/温度/浓度/压力；坐标是**场坐标(x,y)**而非必须经纬度，用于选址/最优点判定 |
| 空间连续量 | 等值线图 / 等值面图 | 浓度/温度/成本随空间变化 |
| 组间差异比较 | 哑铃图 / 点图 / 带误差棒柱状图 | 突出均值差异与置信区间 |
| 单个估计的不确定度 | 点区间图（点估计+误差棒/区间） | 参数估计、置信区间可视化 |

### 统计诊断类图种（证明"模型可靠"，最易被漏画）

> 凡采用统计检验、贝叶斯抽样、分类评估、回归诊断的题，除主结果图外**必须补以下支撑图**——它们证明模型的可靠性与显著性，是"模型检验"章节的硬证据。别只画主图而漏掉这些。

| 图种 | 适用场景 | 说明 |
|---|---|---|
| **MCMC 轨迹图**（trace plot） | 贝叶斯/MCMC 抽样 | 多参数链随迭代振荡是否稳定、无漂移，诊断收敛（整条为振荡带，图内不放图例/文字，均值说明放标题）|
| **后验核密度图** | 贝叶斯参数估计 | 后验分布是否单峰/对称，多链叠加对比 |
| **自相关图（ACF）** | MCMC 链、时序 | 判断链的混合/遍历性、时间序列记忆性 |
| **残差诊断图**（残差 vs 拟合 / Q-Q 图） | 回归/预测 | 检验残差是否随机、正态（Q-Q 图对角直线）|
| **ROC / AUC 曲线** | 分类/审核 | 评价分类器性能，AUC 越大越好 |
| **Lift / 容量捕获曲线** | 营销/风控/审核排序 | 评估排序模型的提升效果 |

## 三、创新/进阶图种（提升丰富度，按需选用）

| 图种 | 适用场景 | 亮点 |
|---|---|---|
| **3D 曲面图**（surface） | 两个自变量→一个因变量 | 多维度展示，直观呈现峰谷 |
| **3D 散点图** | 三维特征/三维解空间 | 展示空间分布与聚类 |
| **3D 柱状图** | 二维分类 × 数值 | 多维度对比 |
| 等高线图（contour） | 二元函数、目标函数地形 | 与 3D 曲面互补，读数精确 |
| 小提琴图 | 多组分布 + 密度 | 比箱线图更丰富 |
| 网络图/关系图 | 节点关系、图论模型 | 展示结构，可用 networkx |
| 桑基图（Sankey） | 流量/资源流向 | 展示分配/迁移过程 |
| 瀑布图（waterfall） | 增量构成 | 展示"由总到分"的增减 |
| 堆叠面积图 | 多成分随时间演进 | 展示结构变化 |
| 平行坐标图 | 高维方案比较 | 多目标优化帕累托解展示 |
| 帕累托前沿图 | 多目标权衡 | 2D/3D 展示非支配解 |

## 四、3D 立体图规范（可选，数据适合才用）

- **何时用**：结果天然含两个自变量（如空间坐标 x,y → 成本/温度/浓度）、三个维度（参数1、参数2、目标值），或三维解空间。
- **只选能支持结论的 3D 图，不为凑数硬画**——数据不适合二维/三维就退回最匹配的图种。
- **视角**：`ax.view_init(elev=25, azim=45)` 选一个信息不遮挡的角度；可多角度输出同一结果（"多角度展示"）。
- **配色**：曲面用 `cmap="viridis"` 并加 `colorbar`；散点用第三维映射颜色；黑白打印需仍可辨（加网格线）。
- **可读**：坐标轴标签、刻度、colorbar 标签字体与 2D 图同规格，不得过小。
- **数量控制**：宁缺毋滥，每张必须对应一个明确结论。

## 五、多帧仿真展示规范

仿真/迭代/时间演化类问题，用"不同帧"展示演化过程（**多帧本质是组合图的一种特例**，面板 = 帧）：

- **帧选取**：选有代表性的时间步（初始、中间转折、收敛/终态等 3~6 帧），不要逐帧全放。
- **2D 为主、3D 按需**：二维俯视帧必给（如位置分布随时间）；三维叠加视角仅当数据适合时采用。
- **统一坐标系**：所有帧共用同一坐标范围与配色，便于跨帧对比；每帧在图内标注时间步/迭代次数。
- **组合排版**：可用子图（`subplots`）把多帧并排，图题写"不同时刻的 XXX 演化"；导出为**单一组合图文件**（一个 PDF/SVG/PNG，登记一条 `FIG-###`），不要逐帧拆成多个文件。

## 六、反模式（避免）

- 一个图塞 5 条以上曲线且无图例。
- 饼图类别 >7 且无标注百分比。
- 若采用 3D 图，视角遮挡数据、无 colorbar。
- 普通基础图种（柱状/折线/散点/饼图/雷达/直方）合计超过 2 种（每子问题内）——违反 §一「基础图种数量约束≤2」硬性规则；必须改用组合图/创新图种承载剩余展示。
- 图无单位、无标题、坐标轴含义不明、字号过小不可读。
- 颜色仅靠红绿区分（色弱/黑白打印失效）。
- 不同量纲指标硬塞进同一 y 轴（会压扁小值柱，改用双 y 轴，见样式规范）。
