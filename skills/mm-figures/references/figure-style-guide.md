# 论文级数据图样式规范与设计原则（mm-figures）

本文件是 mm-figures 的**样式参考**，供 Step 2「按样式规范出图」时查对：配色、字体分工、字号、多面板/组合图布局、DPI、图例、边框、文字重叠防治与导出。设计原则（§九）是"出色而不只是合格"的进阶取向。

## 一、全局配置

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

plt.rcParams.update({
    "font.family": ["Times New Roman", "SimSun"],
    "font.sans-serif": ["Times New Roman", "SimSun"],
    "mathtext.fontset": "stix",
    "axes.unicode_minus": False,
    "text.color": "black",
    "axes.labelcolor": "black",
    "axes.titlecolor": "black",
    "xtick.color": "black",
    "ytick.color": "black",
    "figure.facecolor": "white",
    "axes.facecolor": "white",
    "savefig.facecolor": "white",
    "pdf.fonttype": 42,
    "figure.dpi": 150,
    "savefig.dpi": 300,
    "savefig.bbox": "tight",
})
```

字体分工：**中文正文/图内文字宋体（`SimSun`），中文标题黑体（`SimHei`）；西文、数字、拉丁字母全部 Times New Roman；数学公式用 STIX**。实现方式：`font.family` 用**列表** `["Times New Roman", "SimSun"]`（Times 在前），matplotlib 按字形回退——遇西文/数字用新罗马，遇中文字缺字形自动落到宋体；切勿写 `font.family="SimSun"`（那样西文数字也走宋体）。中文标题需单独黑体时，在对应 `title` 或文本处显式 `fontname="SimHei"`。**注意 mathtext（`$...$`）只支持数学字符，里面不要放中文**，中文字符放普通字符串；若公式需中文说明，用普通过 `text` 而非 `$...$`。

> **关于硬数字**：下列 `figsize`、字号、DPI、间距是**默认起点**，最终以"插入 A4 页面后回读可读、不重叠"为准——不是机械铁律；若版心宽度不同导致图过大/过小，优先调整 `figsize` 与字号，而非强行保留默认值。

## 二、配色（高对比、白底、黑字）

| 用途 | 色值 |
|---|---|
| 蓝色 | `#0066CC` |
| 青绿色 | `#008F78` |
| 橙色 | `#E68A00` |
| 红色 | `#D83A58` |
| 深灰色 | `#657487` |
| 网格线 | `#D7E1EA` |

重要类别**同时用颜色、线型和点形区分**；网格只保留有助于读数的方向；禁止深色底、渐变、阴影卡片、灰暗低对比配色和装饰纹理。

**配色语义化**（编码变量，而非美观）：连续变量 → 连续色带（`viridis`/`magma` 或线性/对数映射的单一色带），不把离散类别色硬套连续值；分类变量 → 有限且稳定的类别色（每类一个稳定色、跨图一致，不换色）；风险/阈值/异常 → 强调色（单个高对比低饱和色如红/橙，只在真正需警示处用）。任何颜色都同时用线型/点形/填充冗余编码，保证黑白与色弱仍可辨；颜色必须承载语义，禁止纯装饰性配色。

## 三、画布与字号（含多面板/组合图布局）

- 核心统计图优先 2×2 多面板，四个子图围绕同一问题；推荐 `figsize=(7.80, 4.39)`（接近 16:9）；子图标记统一 `(a)(b)(c)...`。
- **多面板布局模板**（`fig.subplots(nrows, ncols)`）：按信息量与论证链选择——1×2（左“现象/分布”、右“结果/拟合”对比）、2×2（四个角度/方案/阶段）、1×3（三个参数或三种方案串联）、2×3（两组 × 三种情形）、1×1（单图，仅当结论无法再拆）。长宽比随面板数与版心宽度调整，优先用 `figsize=(7.80, 4.39)` 或 `(6.66, 4.39)`，不强行统一；最终以 A4 版心插入可读、不重叠为准。
- **共享元素**：同一组合图内面板，凡度量一致就**共享 y 轴范围**（`fig.subplots(... sharey=True)`）或共享 x 轴，跨面板轻易对比；同一指标跨图用同一视口、单位、配色。组合图的**图例/标题/轴标签**尽量收敛到整张图（`fig.suptitle`、`fig.supxlabel`、`fig.legend`），减少每面板重复；仅当各面板标签确有差异才各自标注。
- **配色跨面板一致**：组合图内相同类别用同一稳定色，不跨面板换色（见 §二"配色语义化"）。
- **面板标记**：每个面板左上角标 `(a)(b)(c)...`（`ax.text(-0.10, 1.06, tag, transform=ax.transAxes, ...)`），标记不得与标题/刻度重叠。
- 轴名和刻度 7.5~9 pt，图例 6.5~8 pt，子图标记 10~11 pt。
- 最终判断以插入 A4 页面后的可读性为准。

## 四、图形选择（模型/审核类）

| 数据关系 | 图种 |
|---|---|
| 模型排序 | ROC、AUC 区间或置换结果 |
| 审核效果 | 容量捕获曲线、Lift 曲线 |
| 参数不确定性 | 点区间图 |
| 分组比例 | 带 Wilson 区间的柱形图/点图 |
| 小样本分布 | ECDF |
| 字段闭合 | 点图、哑铃图或误差对比图 |
| 建模流程 | 对齐方框 + 正交箭头（流程图归 `mm-graphics`） |

3D 图的**是否采用、视角、配色、colorbar、刻度控制与可读性**全部见 `chart-type-catalog.md` §四「3D 立体图规范」，此处不重复；仅一条与本文件相关的红线：3D 图的轴标签/刻度/colorbar 字号与 2D 图同规格，不得过小。

## 六、文字重叠防复发（常见布局陷阱）

数据图交付前必须通过 `python <mm-figures目录>/scripts/check_figure_overlap.py` 扫描，并逐项检查以下**高发场景**。该脚本分两层判定：

- **文字-文字重叠**（硬性 FAIL 门槛，不变）：任意两文字 span 包围盒水平/垂直重叠 >2pt 且重叠面积 >15% 即报 `[OVERLAP]`，存在即 FAIL，禁止进入 `docs/04` 与论文。
- **文字-数据主体候选**（`[DATA-CAND]`，默认只提示不 FAIL）：文字 span 与**数据主体图元**（曲线/柱/散点/误差带/热力色块等非白底、非网格线、非坐标轴/刻度细线的图形）的细分几何重叠时，输出候选作为"可能遮挡"提醒，**交人工终判**（有的候选是有意标注如带引线的关键解，不算缺陷）。用 `--strict-data` 可把这类候选也计为 FAIL。

> ⚠️ **候选≠缺陷，仍需视觉回读终判**：脚本能自动**标出**"文字可能压到数据图形"的位置，但**无法自动判断它是否真缺陷**（带引线标注、图例有意贴曲线、轴标签紧邻柱顶等可能是有意为之）。因此每张图仍要**肉眼回读**这些 `[DATA-CAND]` 候选，确认图例框、数据标签、节点标注、colorbar 是否**真的遮住了**曲线/柱/散点/误差带/热力色块。真遮挡即返工；有意标注可保留但须视觉核准。**机检负责"聚焦可疑点"，人工负责"定真伪"，两者缺一不可。**

1. **多面板/子图行距**：底部面板标题不得与上排面板的刻度、x 轴标签重叠。实现：`fig.subplots_adjust(hspace=0.55, wspace=0.25)`（或更大）；上排 xlabel 与下排标题之间必须肉眼可见空隙。组合图面板数越多（1×3、2×3 等）或刻度标签越多（15 个 y 刻度、旋转 45°/90°）时，会向下/向外溢出，需缩小刻度字号或加大 hspace，不能用默认行距赌运气。
2. **面板标记**：多面板组合图必须标 `(a)(b)(c)...`（`ax.text(-0.10, 1.06, tag, transform=ax.transAxes, ...)`），标记不得与标题/刻度重叠；面板数 >4 时更要注意标记与相邻面板刻度的间距。
3. **图例**：优先放**数据稀疏区**，且**不得遮挡任何曲线、柱、散点、误差带**。放在图顶部时不得压面板标题；放在图内右上/左上等位置时须先目测该处是否有曲线穿过，有则换到稀疏区或移到图下方（`fig.legend(..., bbox_to_anchor=(0.5, -0.05))` 并给底部留白 `fig.subplots_adjust(bottom=...)`）。**双向风险**：图例框压图形、或图形高点压住图例文字，都要返工。这类"图例压曲线"是脚本 `[DATA-CAND]` 重点提示的场景，务必人工回读确认。
4. **热力图**：矩阵 ≥10×10 时，数值标注只放内圈单元格（跳过最外圈行/列）或缩小字号并加大画布；colorbar 避免与右缘/底缘标注及旋转刻度相交（必要时改底部横向 `orientation="horizontal"` 并加大 `pad`）；`ax.tick_params(pad=6)` 分隔刻度与图形。
5. **3D 图**：限制刻度数量（如 `set_xticks([0,1,2,3,4])`），轴标签 `labelpad≥10`，扫描确认刻度标签与轴标签不重叠。
6. **堆叠柱小标签**：小计数段（v<2）不标注或加大偏移（`y+v+1.0` 以上），避免相邻数值标签重叠；计数标签字号 6pt 左右。
7. **旋转刻度**：`rotation=45/90` 会显著扩展标签占位，必须为 xlabel、相邻面板、colorbar 预留空间。
8. **图内无干净区（整片散点/密集振荡/满格色块）**：MCMC 轨迹图、对象着色标量场（定日镜场分布）、密集散点、满幅热力等**整张图都是图形元素、几乎没有空白区**的图，图例/数据标签/文字标注**放哪都会压到图形**。处理：①标注/说明文字放**图外**（标题、colorbar 旁、图下方）；②确需图内标注用**引线 + 白色圆角底框**（`ax.annotate(..., bbox=dict(boxstyle="round,pad=0.35", fc="white", ec="gray", alpha=0.92))`），用白底隔开文字与图形；③这类图**不带图例框**或用标题说明，图例不硬塞进图内。

上述任一场景存在重叠（**含文字/图例压图形这类机检查不出的视觉重叠**），必须返工后重扫并回读，禁止带病进入 `docs/04` 与论文。

## 七、导出

每张终稿图（含每张组合图）同时导出 PDF、SVG 和 PNG：PDF 用于 LaTeX，SVG 用于编辑，PNG 用于检查与支撑材料。PNG 不低于 300 DPI，多面板图推荐 420 DPI。**组合图以整张图为单位导出**——一个文件包含全部面板，三格式同名（如 `多方案对比.pdf`/`.svg`/`.png`）；不把面板拆成多个文件，除非正文确实需要单独引用某面板。

## 九、设计原则（出色，不只是合格）

数据图不只是把结果画出来，更要让评委**不靠解释就能沿图的结构读出建模逻辑**。以下四点在本 skill 出图全程适用，与选图标准（`chart-type-catalog.md`）配合执行：

1. **中文无乱码/方框**：所有中文（轴标签、图例、标题、数据标签、注释）必须正常显示，不得出现缺字方框、乱码或替换字符。中文走宋体（`SimSun`）、中文标题走黑体（`SimHei`），西文/数字走 Times New Roman（`font.family=["Times New Roman","SimSun"]`）；设置 `axes.unicode_minus=False`，出图后回读确认；字体缺失导致的方框一律返工，**禁止用拼音或英文替身顶替中文标签**（西文/数字用新罗马，而非用宋体凑）。
2. **高级感＝结构可读**：图的视觉结构本身要能读出版（数据→模型→结果）的建模逻辑。做法：用多面板/组合图梳理论证链，每个面板承担一个明确环节并用 `(a)(b)(c)...` 对齐；统一视觉动线（从上到下/从左到右）；同一指标跨图用同一视口、配色与线型；图内含关键结果标注（数值、单位、结论性注释），一眼能定位"结论在哪、依据是什么"。高级感来自**取舍后的结构与节奏**，不是信息堆得越多越好（"何时合并、何时拆开"的取舍见 SKILL 组合图判定）。
3. **配色语义化**：配色编码变量而非美观（连续→连续色带、分类→稳定类别色、风险/阈值→强调色；任何颜色同时用线型/点形/填充冗余编码），**详见 §二「配色语义化」**，此处不重复。
4. **场景创新型**：让评委看到模型在解决**真实问题**，而不仅是统计图。医学、交通、能源、生态等题尤其要体现"场景—模型—决策"的关联。数据图可内嵌小的**机制示意/场景标注**（对象、空间时间结构、真实站点/人群/资源），把关键结果落在真实对象上。若一张图的主体是纯机制/场景、而非数据结果，则**转交 `mm-graphics`**；数据图内嵌的机制/场景只作辅助，不能喧宾夺主。
5. **关键统计量上图（拟合/回归/时序类）**：拟合曲线、回归对比、时序拟合等图件在图内直接标注关键统计量（调整 $R^2$、拟合方程、最优值/置信区间端点），使一图自带模型证据；标注用引线或白底圆角框避让曲线与数据点（衔接 §六 文字重叠防复发规则），无统计量可标的图不硬标。
