# 训练/测试隔离与独立复核手册

## 1. 隔离纪律

- 训练集负责字段选择、标准化、变量筛选、超参数、技术阈值和决策参数；
- 测试集只在规则全部冻结后用于一次性外部评价；
- 禁止用测试集调参或反向修改模型；测试集字段闭合率、哨兵异常和 PSI 只作部署诊断；
- 身份编码、机构编码不得进入评分器；
- 泄漏审计：日期重复、总计字段、ID 交集、重复行、目标变量出现在特征中。

## 2. 独立复核

除主分析程序外，写独立复核脚本，复算：

- 公式与指标：AUC、分类指标、字段闭合、容量收益、成本曲线、标签隔离；
- 与主程序结果对比，误差超阈值（如 1e-6）即定位并修正；
- 复核结果写入 `docs/03-results-report.md`。

## 3. 必出结果

- 交叉验证均值与波动（mean ± sd），不只最优一次；
- 容量指标 Recall@B / Precision@B / Lift@B（B = 50/100/150/200）；
- 风险因素的 Bootstrap 区间与方向一致率；
- 聚合方式的敏感性比较（AUC 与 Top-B 名单）；
- 测试集一次性外部评价结果。

## 4. 落盘与可复现

结果命名 `qN_含义.csv`；固定随机种子、记录输入 SHA-256（并入 `results/复现清单.json`）。
