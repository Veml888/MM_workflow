# 非数据图·逐类画法字典（references/line-art-syntax.md）

> **路由**：画图前先在 SKILL §二"视觉风格决策与路由表"定位类别，再读本文件对应小节，按该节执行。
> 通用规则（设计令牌、文字与节点尺寸、连线硬规则、TikZ 几何、硬性要求、验收）以 SKILL §3.2/§3.3/§3.5/§3.6/§5.1 为准，此处不重复；画完按 SKILL §5.1 逐条自查。

## 1. 逻辑/流程类（技术路线、数据管线、机理框架、泳道、指标树、决策树、反馈闭环、模型结构）

**子结构选型**：

| 逻辑任务 | 首选结构 |
|---|---|
| 全文建模思路 | 分层技术路线 |
| 数据清洗、转换与特征构造 | 数据处理管线 |
| 输入—机制—输出与约束 | 机理框架 |
| 多主体职责与交接 | 泳道图 |
| 目标—准则—指标 | 树状指标体系 |
| 判断与多种结局 | 决策树 |
| 模型建立—检验—修正 | 外围反馈闭环 |
| 多模块依赖 | 有向模型结构图；复杂时拆为总览与局部图 |

具体算法求解步骤、迭代伪代码和软件操作步骤不得画成流程图，使用正文编号或伪代码环境。

**版式选择（画图前先定）**：节点 ≤5 步用纵向单列（单栏 8–9cm）；6 步及以上用双列下行（左列前段、右列后段，跨列线走列间走廊，高度约减半，避免 8 节点以上纵向单列占高超 12cm 挤占版面）；多模型并行、分阶段求解用分层技术路线（层间点线分隔 + 左侧层标签，通栏 13.5–15cm）。

**各子结构画法**：
- **分层技术路线**：按"问题理解—模型构建—求解验证—结论"分层，每层内部可并列。使用细分隔线或层标题，不使用四张大卡片。
- **数据处理管线**：保持单一横向或纵向主链；清洗、转换、特征与输出语义明确。多个同源步骤使用母线扇出，多个结果使用汇聚线，避免蜘蛛网。
- **机理框架**：只有真实存在输入、机制、输出和外部约束时才使用相应分区。外部约束可通过顶部窄带、外围注释或边界条件表达，不默认画成四区面板。
- **泳道图**：泳道只在主体职责和交接是论证重点时使用。泳道标题窄而稳定，跨道边突出交接；同一主体内部流程保持对齐。
- **指标体系树**：父节点位于中心或上方，子节点等距展开。连接线使用共享主干，避免每条边独立拉回父节点。层级不超过 4 层；更深时拆图或改用表格。
- **决策树**：判断节点出口必须标注条件；同一深度对齐；成功与失败分支位置在全图保持一致。叶节点多于 8 个时考虑拆分。
- **反馈闭环**：主链保持直线，反馈沿最近外侧轨道虚线返回目标节点。不要让反馈线跨越多个无关分区；必要时使用编号式反馈标记而不是超长回线。
- **网状模型结构**：先按层级或模块分组，再做有向布局。交叉边目标为 0；若超过 2 条，优先拆为一张总览和一张局部关系图。

## 2. 空间坐标/实体/几何（天球、三维坐标、几何构型、投影）

场景/空间精确示意图，按题面事实绘制。理想形态是**可打印的黑白/灰线稿立体图**，绝非伪3D卡通或 AI 生图。视觉语法六条：

1. **线稿优先，节点无填充**：细实线（可见结构）+ 细虚线（被遮挡、隐藏边、辅助投影/支撑线）；背景纯白，不用彩色、渐变、阴影、底纹或大面积色块。强调某对象用加粗线，不用色块。
2. **真实投影画立体**：球面、地面圆等平面圆在透视下画成**椭圆**（`cos/sin` 参数方程压相应轴），比例与倾角须符合题面或模型坐标。
3. **坐标圈与方向保留**：坐标轴、经纬圈/方位圈、N/S/E/W 方向标与单位是消除歧义的对象名，不可混入装饰。
4. **角度与弧**：角度用"两条方向之间的等半径圆弧"标注（`arc[start angle=…, end angle=…, radius=…]`），旁带希腊字母（$\alpha_s,\gamma_s,\delta,\omega$）；不得用粗箭头扇形、渐变扇面或大色块强调角。
5. **参照点与投影**：关键点（天顶、太阳、观测点、极轴端点等）用实心小圆点；投影线、量角支撑线用细虚线，与被画主体区分。
6. **引线标注**：文字标签走"细引线 + 小箭头"指向对象，`anchor` 避开重复与压线，标签为名词短语、放画面外围；最终物理尺寸不小于 8pt。

**事实与构图约束**：
- 所有对象、相对位置、比例与关系必须能追溯到题面、模型或结果；按题面给出的坐标、尺寸、角度绘制，禁止虚构事实或夸张比例。
- 一张图一个主命题；视角（平面/剖面/鸟瞰/轴测）按最能表达论点者选；约束画成边界、禁区、可行域等语义元素，不默认画成面板。
- 保留会消除歧义的对象名、变量、方向、单位；标签为名词短语。
- 几何与拓扑用 TikZ（坐标精确、可编译验证）；复杂自由构图可用 SVG（`render_svg.py`），文字标签与拓扑必须精确。
- 位置选择：列出不少于两个候选正文位置，按"信息增益/正文关联/非重复性/叙事连续性"择优；场景图优先放问题重述首次完整介绍对象与规则的段落后，空间关系图放研究对象与关系定义之后。
- 验收：SKILL §3.7 Step 5 自动审查 + §5.1 论文级验收。

## 3. 结构/装配（爆炸图、组件组合）

- **画什么**：零件→组件→成品的归属关系、层级。
- **实线**：装配引导箭头（细实线+小箭头）。
- **虚线**：爆炸拉开后的辅助托座/隐藏关系。
- **点**：汇入点小圆点。
- **引线**：分组标题（第一级/第二级）用细引线标注。
- **避免**：装饰性零件图标、彩色包装感色块。本类可用白底细框节点表达零件名，不用任何填充色。

## 4. 分布/统计（概率曲线、接受域/拒绝域、置信区间）

- **画什么**：概率密度曲线、坐标轴、临界值、区间。
- **实线**：主曲线、临界竖线、坐标轴。
- **浅灰区域**：拒绝域/置信带（**仅一种极浅灰**，属唯一合法的"填充"例外）。
- **点**：临界值、峰值实心小圆点。
- **引线**：区间名、临界值名用细引线+标签。
- **避免**：彩色多色置信带、装饰性标注曲线。

## 5. 规划/可行域（线性/整数规划）

- **画什么**：约束边界直线、可行域多边形、目标等值线、最优解。
- **实线**：约束线、可行域边界、坐标轴。
- **浅灰区域**：可行域填充（仅一种极浅灰，合法例外）。
- **点**：最优解、顶点实心小圆点。
- **引线**：可行域、最优解、等值线用细引线标注。
- **避免**：多种颜色区分约束、装饰性箭头。

## 6. 状态/转移（状态机、马尔可夫链）

- **画什么**：状态圈、转移箭头、概率/条件标签。
- **实线**：转移箭头（细实线+小箭头）、状态圈。
- **虚线**：非主转移/自环可用细虚线或小圆点。
- **点/圈**：状态用空心或实心小圆；双圈表示吸收态/终态。
- **标签**：每条转移边写转移概率或条件。
- **避免**：彩色填充状态、加粗大口径箭头。

## 7. 网络/图论（加权图、网络流、路径）

- **画什么**：节点、边、权重标签、起终点。
- **实线**：确定边（细实线）。
- **虚线**：候选边、可选择边。
- **点**：节点实心小圆。
- **标签**：每条边写权重；旁注图例（实=确定、虚=候选）。
- **避免**：节点填充色、装饰性图标。

## 8. 时序/调度（甘特图、工序时间轴）

- **画什么**：时间轴、工序区间、事件点、检修期。
- **实线**：时间轴（带方向箭头）、正常工序区间（白底细框或细线矩形）。
- **虚线**：检修期、可调整/预留区间。
- **点**：工序开始/结束事件点。
- **引线**：工序名、检修期名、图例用细引线标注。
- **避免**：彩色工序条、装饰性进度图。

## 9. 符号定义/物理场景（向量、法向量、夹角、坐标系）

模型构建中为让符号具有"具体实际意义"而配的定义图。对应 mm-paper-writing 05 章"公式/符号的图形化辅助"第⑥类。

- **画什么**：符号所指的几何对象本身——入射/反射/出射向量、法向量、二者夹角、坐标轴与正方向、物体安放姿态等。
- **推荐双联画法**：**(a) 抽象几何定义**（纯几何：地平线/平面直线 + 各向量 + 夹角弧 + 符号标注）+ **(b) 实际场景**（对象安放姿态：支架、平面、向量群方向）。(a) 给准确定义，(b) 给直观物理对应。
- **实线**：向量本体用带箭头实线，向量族用同色平行箭头；物体轮廓用实线。
- **虚线**：向量的平移辅助线、延长线、几何分解辅助线（如向量合成的平行四边形虚边）。
- **颜色**（"最多 3 个语义色"的典型合法场景）：不同向量族各占一个语义色（如入射红、反射蓝、法向黑）；夹角弧与角度符号跟随相关向量。
- **标注**：向量符号（$\vec u_i,\vec v_i,\vec n_i$）标在箭头附近；夹角用等半径弧 + $\theta_i$；必要时子图标注 (a)(b)，总图题外置。
- **避免**：向量族同色导致混淆；漏掉夹角弧使 $\theta$ 无所指；场景图比例失真。

## 10. 物理机理场景（遮挡/阴影/覆盖，双联对比）

模型中存在"对象之间的空间因果"时画的机理图——谁挡住谁、影响哪块区域。典型机制：遮挡、阴影、可见性/通视、覆盖、干涉、安全距离；典型公式挂钩：遮挡效率、阴影损失、覆盖率、阴影长度 $L=h\cot\alpha$ 等。某公式项或效率系数的物理来源是这种机制时，在该公式首次出现处配图。

- **双联对比**：两个对称/互补的机制各占一联（反射遮挡 vs 入射阴影；冬季长阴影 vs 夏季短阴影），两联**共用同一套物体画法**，只换发生条件。
- **技法**：
  1. **空间平面画平行四边形**（仿射投影）：与"圆斜视变椭圆"同一原理；同图内所有平面的倾斜角必须统一。
  2. **光线/影响路径 = 带箭头直线 + 标号**；**临界路径（恰好擦过角点/边界的）用虚线**——正是临界线划出影响区的边界。
  3. **全图唯一语义填充给"主角区域"**（被遮挡区/阴影区/覆盖区），颜色极浅；物体本身一律白底不填充。
  4. **影响区顶点由几何计算得出**（角点沿方向投影到目标面），必须与模型计算一致，不得为美观随手画。
  5. **关键量直接挂钩公式**：角度弧 + 符号（$\alpha$）、长度双箭头（$L$、$h$）标在图上，使图成为公式 $L=f(h,\alpha)$ 的几何解释。
- **避免**：多块区域同时填色；临界线画成实线；区域顶点与计算不符；两联物体画法不一致。
