# 数学建模概念图设计与验收手册

## 1. 路线判断

| 需求特征 | 首选路线 | 原因 |
|---|---|---|
| 场景、空间、对象互动、环境影响 | imagegen | 需要视觉先验、材质与整体构图 |
| 精确节点、边、变量、公式、中文标签 | SVG | 需要确定性和可编辑性 |
| 丰富场景中叠加精确路径或变量 | 混合 | 分离视觉生成与精确标注 |
| 主要承载数值 | mm-figures | 概念图不应代替数据图 |
| 需要按步骤阅读完整过程 | mm-diagrams | 属于流程表达 |

## 2. 论文放置位置选择

每篇完整论文至少配置 1 张视觉示意图。先列出不少于两个有实际意义的候选位置，再选择总分最高者；不要先画图再寻找空位。

| 评分项 | 权重 | 判断问题 |
|---|---:|---|
| 信息增益 | 40% | 这张图是否显著减少读者理解题意或模型的时间？ |
| 正文关联 | 25% | 相邻段落是否直接解释图中的对象和关系？ |
| 非重复性 | 20% | 是否避免重复已有数据图、流程图和公式？ |
| 叙事连续性 | 15% | 插入后是否自然承接前文并引出后文？ |

优先锚点：

- 题目场景图：问题重述中首次完整介绍对象与规则的段落之后。
- 空间或对象关系图：定义研究对象、区域、网络或交互关系之后。
- 模型机理图：核心假设和变量定义完成、正式列模型方程之前或之后，以理解顺序为准。
- 算法隐喻图：算法思想首次完整说明之后、伪代码或参数设置之前。

不要把图放在章节开头而前文没有引入，也不要集中堆在结果章节末尾。报告必须给出章节名、段落/公式锚点、选择理由和建议图注；能编辑论文源文件时应实际插入。

## 3. 常用构图骨架

构图由信息关系决定，不把它们当固定模板。

- 空间场景：地图式、剖面式、鸟瞰式、轴测式。
- 对象交互：中心辐射、双主体对峙、网络生态、局部放大。
- 状态变化：前后对照、连续快照、环形反馈、能量地形式。
- 搜索与优化：候选空间、收缩包络、路径竞争、局部—全局对照。
- 多尺度机制：全景 + 局部放大窗，或上下分层。
- 约束作用：把约束画成边界、阻力、容量、禁区或可行域，不默认画成右侧面板。

一张图只保留一个主视觉命题。次要信息通过尺度、明度、饱和度、透明度或局部框选降级。

## 4. 视觉语言

### 色彩

- 默认使用克制的论文配色：1 个主色、1 个强调色和中性色。
- 颜色必须承载语义，例如状态、阵营、风险、流向或阶段；不要只做装饰。
- 同时使用形状或线型提供冗余编码，避免只靠颜色区分。
- 若论文要求黑白打印，检查灰度下是否仍能区分。

### 文字

- 保留会消除歧义的文字：对象名、变量、方向、单位、关键状态。
- 标签优先使用名词短语，避免句子。
- 生成式路线中的精确文字应后期用 SVG 叠加。
- 最终尺寸下正文标签建议不小于约 7.5–8 pt；图题不嵌入画布，除非版式明确要求。

### 线条与箭头

- 同一语义使用一致线型；不同语义必须有可解释差异。
- 主路径最显著，辅助关系减淡，避免所有箭头同权重。
- 连线不得无意义穿过主体；交叉不可避免时使用桥接、分层或重新布局。

## 5. imagegen 制作规格

将请求整理成以下短规格，只填写有用字段：

```text
Use case: scientific-educational
Asset type: mathematical modeling paper concept figure
Communication goal: <5 秒内要看懂什么>
Source facts: <必须忠实呈现的对象、数量、关系与约束>
Scene and viewpoint: <环境、视角、空间结构>
Composition: <焦点、动线、层级、留白>
Visual style: <学术插画/轴测图/扁平矢量感/3D 等>
Color semantics: <颜色分别表示什么>
Text: <无文字，或仅列允许出现的准确文本>
Constraints: no extra objects; no invented relationships; no watermark; no decorative gibberish
Output intent: publication-ready, clean edges, readable at paper size
```

生成后每次只针对一个主要问题修改，例如“保持所有对象与构图不变，只增强可行域边界”。迭代时重复事实约束，避免语义漂移。

## 6. 混合路线

基础图应尽量避免生成文字、公式、细箭头和精密边界。将这些内容放入 SVG 覆盖层：

- 编号与短标签；
- 路径、方向箭头和轨迹；
- 可行域、禁区和阈值边界；
- 数学符号、公式与单位；
- 图例和局部放大框。

覆盖层必须与基础图透视、焦点和配色协调。不要把二维标注机械贴在强透视场景上。

## 7. 验收量表

每项 1–5 分，五项均至少 4 分才可标记通过。

| 维度 | 5 分标准 |
|---|---|
| 语义准确 | 对象、数量、方向、关系和约束均与来源一致，无虚构 |
| 5 秒可读性 | 不读正文也能识别主题、主对象和核心关系 |
| 构图层级 | 焦点明确，视觉动线自然，主次权重与信息重要性一致 |
| 风格一致 | 透视、光照、线条、图标、标签和配色属于同一视觉系统 |
| 论文适配 | 最终尺寸清晰，留白合理，无水印乱码，彩色与灰度均可用 |

### 一票否决

- 与题面或模型矛盾；
- 生成多余对象、错误数量或错误方向；
- 关键标签、公式或单位错误；
- 主体被裁切、遮挡或在论文尺寸下不可辨认；
- 水印、乱码、伪文字或明显生成瑕疵；
- 视觉效果掩盖核心关系。

报告中写出每项分数、证据、修改记录和已知限制，不使用无证据的 `visual_review: passed`。
