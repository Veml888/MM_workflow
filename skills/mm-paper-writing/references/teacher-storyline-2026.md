# 论文故事线与降低模型腔

## 1. 故事线

全文按"问题 → 障碍 → 选择 → 证据 → 转折 → 决策 → 边界"推进，不用文学比喻：

1. 问题重述：真实决策目标和各问要求；
2. 问题分析：数据规模、字段口径、类别不平衡等困难；
3. 字段审计：先回答哪些数据能用；
4. 低自由度模型：第一版排序/基准；
5. 外部测试：训练内评价能否迁移（全文关键转折）；
6. 风险因素与数学机制：解释排序依据；
7. 容量与成本模型：把得分转化为决策动作；
8. 稳定性检验：结论可用到什么范围。

每节开头承接上一节留下的具体问题，每节结尾落下一个可复算结论并自然引出下一节；衔接靠事实，不用"下面进一步研究"。

## 2. 摘要

摘要是全文故事缩写，依次写：数据困难 → 字段处理 → 模型 → 测试结果 → 关键因素 → 审核决策 → 创新点 → 适用条件。每项创新写成实际动作并配关键数值。

## 3. 结论

按问依次回答。每段包含方法、数字和判断；最后一句只写应用条件，不重新总结全文、不升华到行业或未来。

## 4. 降低模型腔

- 每个主要段落加入数字、公式、字段关系、程序结果、失败结果或选择理由；
- 效果有限时直接写 AUC、区间、Lift 和名单稳定性；
- 写清放弃复杂模型、固定分层或虚假概率解释的原因；
- 相同限制只在摘要、结果和结论中各保留必要的一次；
- 技术名词一致，不做无意义同义词轮换；
- 段落长度随内容变化；
- 删除"本文将从三个方面展开""值得注意的是""需要指出的是"等路标；
- 删除"完整回答三问""形成可执行闭环"等空泛评价；
- 图题和表题不写作者备注、读图提示和后续计划；
- 不在正文中保留给模型或作者自己的提示语。

## 5. 冷读检查

完成初稿后冷读每段，问四个问题：

1. 这段新增了什么证据？
2. 能否原样放进另一篇论文？
3. 结论是否超过材料？
4. 删掉最后一句是否更有力？

没有新增信息的段落合并或删除。
