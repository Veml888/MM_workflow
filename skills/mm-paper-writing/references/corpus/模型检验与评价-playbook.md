# 模型检验与评价 playbook

> **定位：语料证据**（检验手段统计与示例），不是操作规范；检验、灵敏度/鲁棒性、评价（示弱式缺点）的写作要求以 `references/cumcm-paper-structure.md` 与 SKILL.md 硬性要求 6 为准，冲突时以操作规范为准。

> 基于 28 篇国赛优秀论文语料(2020–2025)统计。检验与评价是获奖论文与普通论文的分水岭。跨年验证:检验内嵌为主流(23/28 内嵌、5/28 独立成章),「示弱式缺点」是 28/28 最强共性之一。

## 1. 模型检验:手段清单(语料实际出现)

| 手段 | 说明 | 语料示例 |
|---|---|---|
| 拟合优度 | R² / AIC / BIC / MAE / RMSE / MSE | 2023 C235、E176(R²=0.8013)、B477;2020 B(R²=0.9952);2021 B026(R² 最高 99.95%);2025 C023(R²=0.8962) |
| 假设检验 | 显著性检验(p<0.01/0.05)、K-S 正态性、F 检验、VIF<10 多重共线性、Fisher、卡方、似然比 | 2023 C050、C126、E176、C228;2021 B026;2022 C155;2025 C023(似然比 LR=41.29) |
| 误差/残差分析 | 预测误差表、标准化残差直方图、误差不超过阈值(如 0.001)、残差均值≈0、Q-Q 图、自相关检验 | 2023 E176、B311;2025 B157(残差+QQ+自相关+不确定度) |
| 灵敏度/敏感性分析 | 对关键参数做扰动(网格步长、开角、坡度、安装高度、集热器尺寸、离散点密度)看结果变化 | 2023 A127、A175、B226;2025 A196(n=300 兼顾精度效率) |
| 交叉验证 | 训练/测试集划分、两阶段检验(前段建模后段预测)、bootstrap | 2023 E176、C228;2025 C023 |
| 对照/仿真验证 | 两种算法互验(贪心 vs 模拟退火)、特殊情形对照(对称性、0% 重叠率、极端方案)、蒙特卡洛对照 | 2023 B226、B477、A165;2022 B086;2024 C234(进化曲线收敛+极端方案对照) |
| 分类/检测指标 | 准确率、AUC/ROC、F1、精确率/召回率、3σ 鲁棒性 | 2020 C(97.6%/AUC 99.42%);2022 C155(F1=1);2024 B196(3σ) |
| 文献佐证 | 引用规范/国标(如《海道测量规范》GB12327) | 2023 B311 |

- **使用原则**:检验、模型对比、灵敏度和鲁棒性按题目需要选择；凡声称更优、稳定或可靠，必须提供相应证据。
- 放置位置:内嵌在求解末尾(23/28,主流)或独立「模型检验/分析」章(5/28:2023 A165、2021 A115、2022 A022/B086,2020 B 的「模型的讨论和合理性分析」介于独立与内嵌之间)。两种都见诸获奖论文,选一种并保持一致。
- **反例(不能学)**:2024 A163 全文无任何检验;2021 C169 仅有结果自洽核对,无量化检验——两篇是 28 篇中检验最弱的两篇。
- 检验过度也会失衡:2025 B157 检验段几乎与建模段等长,篇幅膨胀。

## 2. 灵敏度分析的写法(加分项)

获奖论文中灵敏度分析常单独成节(2023 A127 第八章)或内嵌结果分析:

```
选择 1–2 个关键参数(目标函数最敏感的输入)
→ 在一定范围内扫描(如网格步长 6→0.25、开角 100°–140°、安装高度 3–6m)
→ 报告结果变化幅度 + 一句结论(「影响小/结果稳定」或「在 XX 处最优」)
```

- 结论要明确:参数变化导致结果变化小于 X% → 模型稳健;或找到敏感区间 → 模型在该区间可信。
- **不要**只贴曲线不加结论。

## 3. 模型评价与推广:三段式(28/28 有评价,14/28 含独立推广段)

```
优点(1–5 条):机理严谨 / 算法高效 / 考虑因素全面 / 模型递进有层次 / 文献佐证
缺点(1–3 条):离散化误差 / 忽略某物理或现实因素 / 计算量大 / 局部最优
改进与推广(0–4 条):换形状 / 加检查线 / 纳入更多数据 / 推广到其他领域
```

- **主动「示弱」是 28/28 篇的稳定共性**:每篇都承认至少一个局限(离散化误差、线性假设、忽略横摇纵摇、初值敏感、数据依赖等)。只会自夸不会自省的论文不符合获奖惯例。
- 独立「推广」段约半数(14/28):2023 年 12/13 有,2020/2024/2025 约半数无——有则加分,没有不算硬伤;但「改进方向」建议保留。
- 缺点要具体(「栅格化有少量偏差」「未考虑检查线」「忽略外延层吸收」),不要笼统的「模型有待完善」。
- 推广要落到具体场景(建筑扫描/无人机地形扫描/冷饮服饰预测/水文周期性分析),不要「推广到其他领域」一句话。

## 4. 结论的写法

- 语料中**大多数没有独立「结论」章**,结论=各问求解末尾的结果表 + 结果分析。
- 若写独立结论章,要点:
  - 每问给一条带数字的结论(直接复用求解结果);
  - 全局结论 1–2 句(方案的总体效果);
  - 不放公式推导,不放新的结果(新结果必须在前文)。
- **反模式**:结论章出现正文没有的新数字/新结论(2023 E176 摘要与 5.4.1 矛盾即此类问题)。

## 5. 检验与评价自检清单

- [ ] 论文中的可靠性、稳定性和优越性主张是否都有对应证据?
- [ ] 不适用的检验是否避免了形式化堆砌?
- [ ] 灵敏度分析(若有)给了参数范围 + 明确结论?
- [ ] 评价章有优点 + 具体缺点 + 具体推广?
- [ ] 至少承认一个局限?
- [ ] 摘要/结论/正文数字三者一致?
