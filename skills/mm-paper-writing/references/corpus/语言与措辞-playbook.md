# 语言与措辞 playbook

> **定位：语料证据**（措辞统计与示例），不是操作规范；去 AI 味与语言规范以 `references/de-ai-writing.md` 为准，冲突时以操作规范为准。

> 基于 28 篇国赛优秀论文语料(2020–2025)统计。中文书面学术语体,向获奖论文看齐。

## 1. 高频过渡词(28/28 篇高频出现)

按出现频率排序:

```
首先 / 其次 / 然后 / 最后           (流程推进,最强出现,几乎每篇)
针对问题一/二/三/四                 (摘要与章节领起词;2020 年用「对于问题X」)
综上 / 综上所述                     (小结、评价段领起)
因此 / 从而 / 故 / 进而             (因果推进)
此外 / 与此同时 / 在此基础上        (并列补充)
通过…可以发现 / 由…可知 / 由此可见  (结果分析领起)
为了… / 考虑到… / 由于… / 根据…    (动机与约束;跨年统计「根据」「通过」「考虑」出现频率最高)
```

- 章节/段落内部按「首先→其次→然后→最后」推进是默认节奏。
- 结果分析段用「由表/图 X 可知/可以看出…」领起。

## 2. 自我评价话术(语料实际出现,可复用)

获奖论文的自我评价句,按功能分:

| 功能 | 例句(语料原文) |
|---|---|
| 精度 | 「拟合精度较高」「预测精度较高」「呈现出令人满意的拟合效果」「拟合情况较好」 |
| 可靠性 | 「验证了模型的可靠性」「该模型与第一问建立的模型得出了相同的结果,验证了模型的正确性」「模型具有较好鲁棒性」 |
| 合理性 | 「本文测线设计具有较高的合理性」「定义、推广模型合理准确」「经过验证,该模型是合理的」 |
| 效率 | 「在较短时间内得到较为精确的结果,大大减少了运行时间成本」「通过三分法降低解空间维度,极大加快了模型求解速度」 |
| 严谨性 | 「全文的建模始终基于数学理性思维,模型建立、结果分析严谨全面」 |
| 真实性 | 「这与海底地形相互印证」「与实际情况相符」 |
| 性能指标 | 「该模型在精确率、召回率、准确率和 F1 系数上均为 1,表示该模型性能良好」「该模型在准确性、稳健性与鲁棒性方面均表现良好」 |

- 使用原则:**自评必须与数字绑定**——「拟合精度较高」后面跟上 R² 数值;「验证了可靠性」后面跟上误差数值(如「误差不超过 0.001」)。
- 自评 1 句即可,不要每段自夸。

## 3. 表达 DNA(语料共性)

- **结论先行**:段首句给出结论,再展开依据(「结果表明…,由表 2 可知…」)。
- **主语规范**:全文以「本文/该模型/该算法」为主语,避免「我们」「笔者」混用;「本文」出现频率最高。
- **确定性语气**:「显然」「一定」「必然」少用,多用「可以」「能够」「较为」;但结果数字处用确定性表述(「求得…为 36.9945MW」而非「约为」)。
- **长短句**:主体用中等长度句,公式推导处用短句;避免一段 300 字以上无标点断句。
- **禁口语化**:「挺好的」「很能打」「差不多」等一律不用;「大概」「差不多」用「约/近似/约等于」替代。

## 4. 术语与一致性

- 模型名、算法名全文**唯一且一致**(不要「模拟退火」与「SA 算法」混用)。
- 符号与单位在符号说明表中定义后,正文引用保持一致(θ、alpha、α 不混用)。
- 数字格式统一:小数位数、千分位、单位书写(「kW/m²」vs「千瓦每平方米」选一)。
- 中英文术语:第一次出现给中文全称 + 英文缩写(如「层次分析法(AHP)」),后文用缩写。

## 5. 措辞反模式(语料实际出现)

- ❌ 自评空泛无数字:「模型效果较好」「结果令人满意」(无任何数值支撑)。
- ❌ 绝对化:「完美拟合」「完全正确」。
- ❌ 摘要与正文措辞矛盾(2023 E176:「成效不佳」vs「成效显著」)。
- ❌ 口语/网络词混入书面语。
- ❌ 段落重复(2023 C235 出现整句重复:「之后认为再从周、月、年等多个维度」;2020 B「模型模型」)。
- ❌ 错别字密集(2020 B「求角解」「博奔论」;2021 B026、2022 A022 错别字密度高)。
- ❌ 摘要预告式冗余(2024 C234「在文章的最后总结了模型的优缺点…」)。

- [ ] 术语/符号/单位全文一致?
- [ ] 无口语化、无绝对化、无重复句?
