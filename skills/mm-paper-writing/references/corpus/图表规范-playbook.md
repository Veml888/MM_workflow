# 图表规范 playbook

> **定位：语料证据**（28 篇统计与反例），不是操作规范；图表数量基线、标题格式、三线表、图表与正文呼应等执行规则以 `mm-paper-writing/SKILL.md`（"图表与格式"节）和 `mm-figures/SKILL.md`（"论文级数据图样式规范"节）为准，冲突时以操作规范为准。

> 基于 28 篇国赛优秀论文语料(2020–2025)统计。图表是评审的第一印象。

## 1. 数量基线(28 篇语料统计)

| 题目类型 | 图数量 | 表数量 | 说明 |
|---|---|---|---|
| 机理/几何类(A/B) | 10–29 张 | 4–11 张 | 图多表少:几何示意图、流程图、结果图 |
| 数据/统计类(C) | 8–28 张 | 7–17 张 | 表多:统计表、回归表、结果汇总表 |
| 综合类(D/E) | 5–41 张 | 7–14 张 | 波动大,视题目而定 |

- 底线:**正文图 ≥ 12 张**(操作规范下限);表按需,仅在内容适合用三线表时再做(操作规范已取消"每问至少 1 表"与"表 ≥ 5"),"符号说明"章仅一个三线表、无需正文引用。
- 篇幅上调时图量同步上调:正文目标 27~30 页(官方上限 ≤30)时,图建议 **12~20 张**,重点放在"模型的建立与求解"章节(机理示意、模型结构、结果图、多帧演化),仍坚持**每图一结论**、图必被正文引用且有解读。
- 排版留白控制:单页底部留白超过约 60pt 即需处理——图宽适当缩小(0.5~0.9\textwidth)、大表用 `\small`/`\footnotesize`、宽图/大表用 `[htbp]`+`\FloatBarrier`,避免单个图/表独占一页造成 200pt+ 空白;不允许用超大的段间距/行距撑页。
- 表格紧凑与字体:本工作流固定表内文字为五号宋体（`\songti\zihao{5}`，10.5pt），图题和表题为小四号宋体；禁止用 `\small`、`\footnotesize` 等相对字号替代。可调整 `\tabcolsep` 与 `\arraystretch`，长文本单元格用居中的定宽列换行；表格结束后恢复小四号宋体正文。
- **插图内部文字字体（与正文一致，硬性）**：插图（流程图/示意图/机理图）内部的文字须与正文同字体——**中文宋体、西文与数字 Times New Roman**，由 `mm-graphics` 的设计令牌保证（xeCJK + SimSun[AutoFakeBold] + Times New Roman，图内禁用 `\sffamily`/雅黑/黑体等无衬线字体）；论文终稿验收时逐图核对，图内若出现与正文不同的字体（如雅黑）视为图文不统一，退回 `mm-graphics` 重出。
- 图表浮动:默认 `[htbp]`,章节边界使用 `\FloatBarrier`;只有必须锁定在解释段后的关键图表才使用 `[H]`。
- **表格克制**:只保留适合表格呈现的内容(结果对比表、必要的特征/参数清单),求解步骤用行文编号/流程图而不用表;能用公式或一句话说清的不用表;表格数宁少勿滥,内容优先写成公式与推导。
- 图不是越多越好:2023 E176 有 41 张图,部分标题重复,已属堆砌边缘;2021 A115 图题格式不统一(换行/挤行)。核心是「每张图都有明确叙事作用」。
- 注意:A/B 类题目图表总量可到 30+ 张(C 类表格可到 28 张),但都要被正文引用。

## 2. 标题格式(主流规范;语料中约 1/3 篇不统一是扣分点)

- 图题:**「图 N 描述」**(编号 + 空格 + 描述),如「图 1 问题 1 的示意图」「图 25 海域逐步划分过程」。无空格/无冒号直接接描述也可(2021/2022 多数如此),但**全文要统一**。
- 表题:**「表 N 描述」**,如「表 5 测线布设参数」。
- 少数篇用「图 N:描述」带冒号(2024 A163、2025 A196),或「图N、描述」带顿号(2020 A)——都可用,关键是全文一致。
- **全文连续编号**是主流(约 25/28);少数用「章.序」两级编号(2024 A163 用图 1.1~图 4.29)或复合编号(2022 B086 用 27.1-27.3),均属少数派,能避则避。
- 图题放图下方,表题放表上方(中文论文惯例)。

## 3. 三线表

- 结果表、参数表、符号表**一律用三线表**(顶线、栏目线、底线,无竖线)。
- 语料中 C050 明确为三线表风格;其他篇转换后无法确认,但三线表是国赛排版惯例。
- 符号说明表列:符号 | 含义 | 单位。

## 4. 图的种类与用途(语料高频)

| 图种 | 用途 | 示例 |
|---|---|---|
| 示意图/原理图 | 解释物理/几何设定 | 多波束测深原理图、定日镜坐标示意图 |
| 流程图 | 建模/算法步骤 | 算法 1 的流程图、总体技术路线图 |
| 数据可视化 | 描述统计、分布 | 箱线图、占比图、时间序列图 |
| 结果图 | 展示求解结果 | 测线设计图、优化结果图、路径规划图 |
| 子图组合 | 多视角对比 | 图(a)(b)并排,用(a)(b)标注 |

- 子图用 (a)(b) 标注,并在图题里说明「(左)…(右)…」。
- 多面板图先声明主面板(参考 nature-skills 惯例):信息权重不同时用非对称布局,不做等分仪表盘。
- 图内文字可读:导出的位图至少 300 DPI;刻度、图例不与文字重叠。

## 5. 图表与正文的呼应

- 正文必须**引用图表**:「如图 3 所示」「由表 2 可知」,不能有正文未引用的孤儿图/表。
- 每张图/表后 1–3 句分析(见建模 playbook 结果呈现节)。
- **图表紧邻相关文字**:LaTeX 中优先用 `[H]`(`\usepackage{float}`)或 `[ht]`+`\FloatBarrier` 把图表固定在首次引用处附近,避免所有图表聚集到页首/页尾或单独成页;顺序为「文字引出 → 图表 → 文字解读」。
- 引用格式全文一致(「图 3」vs「图3」vs「如图3所示」选一种)。
- 语料中的图表引用错误(反例):2020 B 正文引「图16」实为另一图;2022 C155 表号与正文引用错位(表9 vs 表8);2024 C234「如下表1,2」表述不规范。

## 6. 图表自检清单

- [ ] 正文图 ≥ 12 张；表按需(适合三线表时再做),无"每问至少 1 表"?
- [ ] 图题/表题格式全文统一(优先「图 N 描述」/「表 N 描述」)?
- [ ] 全文连续编号,无分章重排、无重号、无跳号(2025 C023 表 2→表 4 跳号是反例)?
- [ ] 三线表?
- [ ] 正文引用全部图表,无孤儿图表、无引用错位?
- [ ] 位图 ≥ 300 DPI,文字不重叠?
- [ ] 数字与正文一致(表内数字 = 摘要数字 = 正文数字)?
