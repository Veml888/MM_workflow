# 问题分析写法（操作规范）

> **本文件是问题分析写作的唯一操作规范**；获奖论文惯例证据（26/28 篇设置独立"问题分析"章）见 `corpus/章节组织-playbook.md`，两处冲突时以本文件为准。

## 1. 结构

- **开头不写总结**：进入本章直接逐问分析，不在最前面放总述段。
- **逐问成节**：每问一小节，标题固定为「问题X的分析」；同一问的多个分析要点合并在该小节，另可设置「各问之间的联系」。
- **总结可选**：即使各问联系紧密也不强制写，联系可用单句承接体现（如"沿用第一问的模型"）；若要写，放在逐问分析之后的独立小节（如「各问之间的联系」），放四问关系、总体求解顺序与技术路线图。

## 2. 每问段落写法（优秀论文逻辑：问题要害 → 应对思路 → 可操作落点）

- **指出问题要害**：开门见山点出题面定义/条件的局限或这问的真实困难（如"重叠率定义只适用于水平海底"），不贴"本题属于 XX 类"的标签。
- **给应对思路**：说明修正方向、关键变量或算法思想（几何关系、贪心、拟合、局部最优→全局最优），说清数据、约束与模型方向。
- **落到可操作落点**：段尾给出这问具体要做什么、交付什么（画简图→推导→计算；评价指标如总长、漏测占比）。可用显式「求解思路：…」标签，也可融入行文，不强制。
- **前后问承接**：后问依赖前问时明确写出（如"沿用第一问的模型"），体现建模链条。
- 每问 1~2 段、约 5~8 句，写足要害与推理，直击要害但不单薄；不提前写公式、数值结果与效果自评；语言遵循去 AI 味规范（不用"首先…其次…"连环、"值得注意的是"）。

## 3. 内容充实与版面联动

- 不以占满页面为目标。某问尚未写清问题要害、分析单位、约束冲突、方法选择理由、前后问依赖或交付边界时，补充相应实质内容；存在重复题意、可合并表达或已由数据审计/模型章节承担的细节时，删减或压缩。不得为消除留白重复论述，也不得删掉必要推理。
- 扩写问题重述后若技术路线图、关键表或后续章节发生漂移，先审计各问分析的内容完整性与冗余。分析单薄时补足缺失推理，文字冗长时压缩重复内容；文字已经完整且紧凑时，再调整图表锚点、浮动参数、关联图组合或局部尺寸。
- 图件缩放必须服从可读性。当改变图片大小不适用、会使标签过小或仍无法消除空白时，允许通过有依据的增写或减写调节相邻正文长度。增写只能补缺失论证，减写只能去冗余或移走章节错位内容；不得倒逼正文注水，也不得通过全局缩小字号、行距或页边距修复局部分页。
- 每次改动问题重述或问题分析后，重新编译并检查从改动页到首张后续关键表之间的所有页面，确认无孤立图页、大块无效留白、图文倒序或关键表脱离首次引出。

## 4. LaTeX 示例

```latex
\section{问题分析}

% 段尾落点可用显式「求解思路：…」标签，也可融入行文（优秀论文多为后者）

\subsection{问题一的分析}

问题一要求预测各区域共享电单车的日需求量。直接对全市总量做时间序列会
掩盖站点间的结构性差异：不同区域的出行强度、通勤与休闲属性不同，同一时刻
有的站点排长队、有的站点无人问津；需求还随星期、天气、节假日明显波动，
且这些因素对各区域的影响程度并不一致。因此先把订单数据按区域与日期聚合，
做缺失值与异常值处理，再构造星期、是否节假日、天气、温度、前一日需求等
协变量，以 XGBoost 为主模型、多元线性回归为基线，用 RMSE 与 MAE 在留出集上
对比精度，并检查预测误差是否集中在特定区域或日期。最终给出未来一周逐日、
逐区域的预测结果，作为后续布点与调度的需求输入。

\subsection{问题二的分析}

问题二要在建设成本、站点容量、覆盖半径等约束下同时决定站点选址与初始
配车。选址与配车相互耦合：站点选在哪里决定了覆盖与成本，配多少车又取决于
该站的需求和周边站点的供给，联合搜索空间巨大，直接枚举或简单贪心都难以
兼顾可行性与最优性。因此先按需求强度、覆盖半径与建设成本对候选点做初筛，
压缩问题规模，再建立总成本最小、取还车便利性最大的双目标整数规划模型，
采用主目标优先、便利性作为约束或加权的方式处理双目标，用遗传算法求近优解，
并针对小规模算例用精确求解器验证解的质量。最后对建设成本、覆盖半径等关键
参数做灵敏度分析，给出不同预算下的布点-配车方案。

\subsection{问题三的分析}

问题三针对早晚高峰时段部分区域供需失衡：通勤方向造成早高峰住宅区缺车、
办公区淤积，晚高峰则相反，车辆调运受时间窗与成本约束，静态的初始配车无法
反映供需随时间的演化，调度方案必须说清何时、从哪、往哪调多少车。因此把
调度建模为综合惩罚最小化问题，将缺车、淤积与调运成本统一计入目标，并考虑
调运时间窗；按时间步推进仿真，模拟车辆借还、调运与站点容量变化，输出多个
时间步的车辆分布帧，检验方案在高峰时段的可行性，同时统计调度总成本与供需
失衡的改善幅度。

\subsection{问题四的分析}

问题四要求设计分时分区定价策略。定价不是简单提价或降价：价格会通过需求
弹性改变各区域、各时段的用车需求，进而影响车辆周转、站点供需与平台收益，
单目标优化容易顾此失彼——过度追求收益会牺牲用户体验，过度补贴又侵蚀利润。
因此先利用历史订单估计分区域、分时段的价格-需求弹性，建立以平台收益为主、
用户满意度和车辆周转率为辅的多目标定价模型，与固定定价方案对比收益与体验
指标，并对弹性系数和运营成本做鲁棒性检验，给出稳健的分时分区价格表。

% 仅当各问联系紧密时保留以下小节：

问题四的定价策略又会改变需求分布。因此求解顺序为：先预测需求，再决策
```

## 5. 排版要求

- 标题：`ctexart` 默认标题为黑体（SimHei）+ 西文粗体编号，视觉上加粗；正文宋体（SimSun）。
- 无页眉：导言区 `\pagestyle{plain}`，页码在页脚中部。
- 技术路线图：放在末尾总结小节（如有），用 `mm-diagrams` 产出的 `figures/fig_roadmap.png`。

## 6. 自检清单

- [ ] 开头无总结段，直接进入逐问分析
- [ ] 每问一小节，标题固定为「问题X的分析」（中文数字），无描述性自定义标题；同一问多要点已合并为一节
- [ ] 每段按"问题要害→应对思路→可操作落点"展开，段尾有明确落点（标签可选）
- [ ] 不贴"本题属于 XX 类"标签，无空泛开头
- [ ] 总结（如有）在逐问分析之后独立成节，且各问确有关联
- [ ] 后问依赖前问时写明了承接关系
- [ ] 无 AI 腔连接词（首先/其次/值得注意的是/综上所述）
- [ ] 标题黑体加粗、正文宋体，无页眉
- [ ] 图片不宜缩放时，是否只通过补缺失内容或删冗余内容调整分页，未注水或删减必要论证
- [ ] 改写后已检查至首张后续关键表，无孤立图页、大块无效留白、图文倒序或关键表漂移
