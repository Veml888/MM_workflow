# 模型的建立与求解

> 本模块是模型章写作与终审的统一依据，按「建立 → 求解 → 结果呈现 → 结果分析」四功能组织：一、二章管建立，三章管求解，四章管呈现与分析。
>
> **硬性范围（先读）**：只有两类**必须遵守**——① 模型章骨架与建立、求解、结果呈现、结果分析规则（见一～四）；② 每问闭合论证链（见一.5）。
>
> **四功能 ≠ 四个二级标题**：正文小节形态仍由一.2 与一.4 决定，四功能只是规则的组织方式。

---

# 一、模型章骨架（硬性）

## 1. 外层：每问独立成章

- N = 题面子问题数（常见 2~4），每个子问题单独设一级标题；前四章（问题重述/问题分析/模型假设/符号说明）固定为一~四，问题章从"五"起，序号随 N 顺延。
- **问题章标题（硬性格式）**：`（该问核心模型/方法名）的构建与求解——问题X`。核心模型名取该问最具代表性、能概括建模思路者（如"期望递归模型"），不得写无对象标题（"问题一的模型建立与求解"）或堆次要算法名。
- **模型收口（每问必做）**：核心公式最后**联立为左花括号方程组（或汇总式）作为"本问数学模型"**，一句"至此，综合式(X)(Y)(Z)，得到……的数学模型为"引出，后续求解引用该式号；禁止散落公式串收尾。模型规模大时**分块嵌套**（外层左花括号+行首模块名标签），模块划分与正文小节一一对应。

## 2. 内层：二级标题体系

- **建模成分（核心）**：二级标题 = 建模成分/子模型/方程/目标名，须有建模信息、能概括该成分；命名随题型定——禁止"模型建立/模型求解/结果分析"等空壳词与"问题X结论"式无建模信息标题，禁止四问套同一对。
- **求解去向三选一（按求解的信息量定，不按模板定）**：
  - **(a) 就地求解（默认）**：一两句可解的成分直接在小节内求解，以"解得/拟合得 + 编号方程或数值"收尾；
  - **(b) 集中求解**：仅当求解自成一体（有算法步骤、关键参数、终止/收敛条件，或多个成分共用同一求解流程）才单设小节，**标题用实际方法名**（如"留一交叉验证与模型形式选择""网格搜索求解"），禁止"模型求解与结果"类组合词；
  - **(c) 集中呈现结果**：结果与解读合并成节时，标题用内容名（如"拟合优度与偏差核查""两情景最优方案"）。

  "建模→求解→结果→解读→边界"闭环**以章内容存在为准，不要求任何标题字面出现"求解/结果"**（由 T-8 闭环检查兜底）。
- 三级小节遵循"**一段 = 一个动机 + 一个公式 + 一句作用**"，标题用名词性学术名，禁止口语化、设问式（合规例：`退化与一致性验证`；问句或口语词改为"对象或成分 + 做法"）；小节数以本题成分定，不凑数。
- **建模准备（可选）**：需铺垫时在第一个建模成分前设"建模准备"类二级标题（如"坐标系与基本方程"）。**边界（硬性）：符号定义归"符号说明"章，准备节不得重复定义符号**；仅本问参数在此给出取值与来源。触发条件（任一）：需约定几何/坐标系；需摆出基本定律或统计假设的原始形式作出发点；需集中给出参数取值。准备节只铺垫、不推导核心模型；纯简单题不设，禁止凑结构。后问反复使用的通用引理可入准备节：先给出并成立，后文直接引用。
- **参数影响探究（可选小节，定位=模型行为理解）**：该问模型含关键可变参数且其规律直接服务后续问题时，可在求解与分析之后设"参数影响探究"类小节：控制变量扫描，出多曲线图并逐图定量解读；无后续决策价值时不设，禁止为凑篇幅扫描。与检验章的分工（硬性）见 05b §四：本节答"量随参数怎么变"，检验章答"结论是否翻转"，互不重复。

## 3. 二级标题组织模式库（按题型，正面模板；标题随题内容化，不得逐字照抄）

**组织总原则**：二级标题按**论证步骤**命名，不按响应/对象机械并列——同一模型下两个响应/对象的平行处理合并为一个建模成分、用三级小节分对象；标题用平实学术词，**禁用工作流内部词（口径、契约、落点、对齐、联动、赋能）**。

| 题型 | 论证链与标题序列 |
|---|---|
| 关系拟合型 | 数据预处理 → 响应关系模型〔三级分响应〕→ 形式选择与拟合 → 拟合优度与偏差核查 →〔稳定性/时序子问〕 |
| 因素效应型 | 因素编码与模型设定 → 效应估计与分解 → 稳健性对照 |
| 优化决策型 | 优化模型 → 求解算法 → 最优方案〔可分情景〕→ 方案可信度 |
| 实验设计型 | 设计准则 → 实验配置与理由 → 与常规设计对比 |
| 机理推导型 | 建模准备 → 机理方程 → 数值格式 → 结果与验证 |

**反模式**：小节以无产出内容收尾（无新方程/数值/表/图/判断，只"奠定基础"）；同一机理由两个响应对象各复述一遍（应共用一次叙述，差异一句话分承）。

## 4. 骨架不变量（只约束"必须存在什么"，不约束环节名称与小节形态；正面标题序列一律见一.3 模式库）

每问章必须满足以下**环节不变量**——顺序可按论证链调整、相邻环节可就地合并，缺一不可（求解与结果由 T-8 闭环检查兜底）：

1. **建模准备**（可选）：仅在需约定几何/参数取值/摆出基本方程原始形式时设；
2. **建模成分 ≥1**：每个成分对应一个真实建模对象，标题内容化；
3. **求解落地**：模型必须被实际解出——就地或集中（三选一规则见一.2），以"解得/拟合得/搜索收敛 + 编号方程或数值"呈现；
4. **结果与解读一体**：结果证据（表/图/数值方程，被正文引用）与解读一并给出——结论性结果按"数值 → 机理 → 决策含义"，描述性结果一句功能性结论或零解读（判据见四.2）；可随成分就地、可集中成节，但不得拆成互不相干的两个空壳小节。

本节加粗词只是环节描述，不是标题要求——环节小节标题一律由模式库命名。**禁止把本不变量当成固定小节序列套用；本节与模式库冲突时，以模式库为准。**

## 5. 每问闭合论证链（硬性）

题目目标 → 数据与已知条件 → 模型选择依据（归问题分析章）→ 变量、参数与单位 → 核心数学关系 → 目标与约束 → 求解算法 → 结果 → 对题目的直接回答 → 证据与适用边界。闭环是硬要求，小节数量和标题名称不是。

# 二、模型的建立：公式与推导（硬性）

## 1. 公式演进链（推导感核心）

相邻公式必须用**数学动作**串起来，而非"给一个式子 + 一段说明"。数学动作：**引入辅助量、代入、化简、展开、分离变量、积分/求导、归结为标准形、代回约束**。典型链：参数方程→引入简记→代入约束→展开→归结为标准形。判据：删掉文字仅凭公式间"代入/化简/得/即"即读懂脉络；若每式孤立、靠文字连接，即为"公式清单"，不合格。

## 2. 引出语与注释行（推导文字的极简规范，硬性）

优秀论文推导段的文字密度极低而信息密度极高：约一句引出语配一个公式，句句是动作。规范：
- **引出语 = 数学动作的宣布**：一句、以动作词开头（"于是有/解得/代入得/整理得/由……可得"），只服务紧邻的下一个公式；一个动作一句话。建模决策（坐标系、微元设计）也压缩为一句直接引出方程。
- **公式后不解释**：注释压缩为"其中：…"一行（变量/参数含义）；禁止"式(X)表明…"式后置解释——机理解释归结果分析；仅每问核心模型式（至多二、三处）可带一句作用说明。
- **几何/位置关系交给图**：配示意图后正文只写"根据图(N)有"+等式链，不用文字描述几何布局。
- **充实感标准**：单位篇幅内可用产出（参数值、方程、关系式）越多越充实；不产生新产出的文字即废话，删。

## 3. 式号粒度：默认一量一式，允许视情况成组

式号分配看**读者是否需要单独引用或检验该量**，不机械一号一拆：
- **默认一量一式**：能被独立推导、独立检验、或后文将单独引用的关键量（目标函数、核心判据、关键中间量）单独编号。
- **可成组（左花括号/aligned 共号）**：①须同时满足的约束组、分段定义；②同一推导步内**同源的联立关系**（如由图一次得出的三行几何关系，作为一个整体产出）；③仅本步使用、后文不再单独引用的临时联立。成组时各行左对齐、组内每行含义明确。
- **反两个极端**：把后文要单独引用的关键量埋进共号组（读者无从引用）；或把一行推导拆成五六个琐碎小式号（编号膨胀）。

## 4. 现场推导

- **公式不许凭空出现**：每式前交代它解决什么、从哪个已知条件出发，**当众算出来**；解析几何/向量法的中间对象（法向量、交线、交点、投影）逐个编号求出，每步一句交代由哪两个已知量经什么运算得到，禁止"由图易知"跳步。
- **题面条件方程化**：题面的约束与参数一律翻译为编号方程或一步推理，禁止文字复述题面后以"由题意"带过。
- **题面给定公式的承接（必做）**：先原样引出题面公式，一句翻译其几何/物理本质，再推广到本题一般情形；推广式在何种条件退化为题面式须显式交代；禁止跳过题面式另起口径。
- **因果链叙事**："因为 A，所以设这个量；由条件 B 推得 C"，文字与公式交织。
- **遇难点先推演再给结论**：易"想当然"的关键点（如单基准点致退化），先现场推演"为何不能这样"再引出改进。
- **方向性中间量保留正负号**，使方向分支自动隐含在公式中。
- **机理题列方程前置约定（机理/动力学题硬性）**：汇总方程前先给逐项源项清单——每项力/源/汇项列明名称、作用对象、与哪个运动量的函数关系（线性化声明）与来源，方程各项与清单逐项可对账；方程含方向性量时，该量首次出现处一句话声明正方向，各项符号与之一致；以平衡/静止状态作初值或判据的，先核算平衡方程再引用。禁止方程组直接"写出"而无清单可查。
- **退化/一致性验证收尾**：每个核心模型给出后，验证退化情形（参数取特值回到已知形式）并给出与已知形式的定量偏差，证明无凭空构造。
- **机理近似可见（硬性）**：凡模型建立在机理/经验定律上，正文必须呈现三层推导链——定律原始形式与符号含义；每条近似的适用条件与半定量论据（极限行为/量级估计/对照偏差有界，三选一）；本题化落点与失效退化处理。“由 XX 定律可知”后直接给拟合式属跳步；无论据的近似降级为“经验形式”，其参数机理解释删除或改称形式参数。本题化落点须以可计算判据呈现——判据量与数值/不等式（如“最大振幅 < 平衡吃水 $h_0=0.99999$ m”），禁止只写“振幅不能过大”式定性声明；求解后须在结果分析处引用判据数值回核一次（见三.4）。
- **建模完整性**：关键变量说明类型、下标、单位、范围与来源；引入理由前置为引出语；作用说明仅对每问核心模型式给出，次要式用"其中：…"注释行；每条约束说明对应资源/容量/守恒/边界。
- **"为什么选这个模型"归问题分析章**：模型建立节只推导，不展开选型评审。

## 5. 公式/符号的图形化辅助

凡公式/符号/约束**具有可直观呈现的空间、结构、几何、关系或分布含义**，应在首次定义处配一张小示意图；示意图为帮助理解服务，不是数据图。

- **值得配图**：几何/空间关系（夹角、投影）、结构层级、分布/区间/边界、状态转移、网络/时序、符号的物理/几何定义。
- **引理图先行（几何关系较复杂时）**：先配抽象示意图证明通用几何关系，再在本题图上锚定符号与数值。
- **迭代过程图化**：方案或解经多轮迭代/细化得到时，把关键中间状态做成多帧图呈现演进——只给最终结果，读者无法判断过程合理性。帧图归 `mm-figures` 数据图或 `mm-graphics` 示意，按内容定。
- **总判断**：图能否帮读者理解公式/符号的实际意义？能则配；只是符号连线、无直观对象则不配。
- **图件时序（硬性）**：动笔写引用图的文字之前，该图必须已完成（`figures/` 有产出、`figure-requirements.md` 状态 `drawn`；先画后写/写作中返回补画双路径见 `mm-graphics`）。严禁写完再补图当装饰。
- **放哪**：紧贴该公式/符号定义处，图注写明"图 X 用以说明式 (Y) 中……的含义"。**怎么画**归 `mm-graphics`（线稿、白底、无填充、黑白灰）。

# 三、模型的求解（硬性）

## 1. 求解路线承接（对上游反查，硬性）

求解动笔前逐问核对 `docs/02-modeling-report.md` 的"求解路线设计表"：

- 判"有解析/半解析路线"的问：求解段必须逐步呈现完整推导链且与 docs/02 一致；上游缺推导链 → 回写 `mm-modeling` 补齐，**不得临场编推导、不得只报数**；
- 判"无解析解"的问：路线表应有已排除技术与原因；正文一句交代为何不可解析（如"幂指数未知，含未知参数的超越方程无闭式"）；
- 数值协议（积分区间/采样窗/步长/暂态排除/由粗到细）按 docs/02 呈现，每项一句依据（如"初始段未达稳态，采样取 200–400 s"）。

## 2. 求解写法两档（按复杂度判档，不按题型；同一问不同成分可分属两档）

判档：求解动作 ≤3 步且无推导/迭代 → 档A；含解析推导链、数值格式推导或迭代/寻优流程 → 档B。求解前先说明模型性质与决策空间规模，再定算法与档位（如"决策变量仅 4 个、组合 16，全枚举即可全局最优"）。

**档A 简单求解——三句封顶，立即可视化**：
①方法/求解器身份与性质一句；②"针对式(N)求解，数据见支撑材料"一句；③一句引出可视化——解完立即给图给表，不写过渡段。写明模型性质、求解器与版本、容差与求解状态，细节登记在结果报告与复现清单；正文不做原理科普、不复述代码流程。

**档B 复杂求解——大篇幅当众推导**：
- 求解段与建模段**同密度**：解析推导、数值格式、迭代公式、估计量构造当众逐步呈现，禁止"用 Python/MATLAB 求解得…"一步带过；
- 推导按二.1 公式演进链执行：每步一个数学动作（引入简记→代入→化简→取模/求导→归结为标准形→一阶条件），长表达式先引入简记（如取 $Y$、$A$、$B$、$C$）再推导；一句引出语配一个公式（见二.2）；
- **解析—数值双轨与标定—推广（硬性）**：两法都存在 → 同表对照（见四.2 验证对照表），对照误差即数值方法的离散/采样精度证据；一般情形无解析 → 呈现顺序固定为"可解析特例的标定对照在前 → 推广到一般情形的结果在后"；
- 由粗到细的数值寻优（粗扫出图→读出峰值/极值区→缩放精化→排序取最优）逐段呈现；读图句写操作性动作（"峰值出现在 [3,4]×10⁴，在此区间作图"），不写成段解释。

## 3. 按工具的写法细则（归入两档执行）

- **解析求值（档A）**：模型已有可直接代入的解析式时，一句话交代五要素——代入对象与全部参数取值、工具、精度口径、结果落点（表/图）；不设"求解算法与实现"类小节、不写伪代码。
- **数值格式（连续模型，档B）**：微分方程离散为**差分/递推格式**（单独编号，如 $T^{(k+1)}=T^{(k)}+\Delta t\cdot f(\ldots)$），交代格式与步长/稳定性依据。
- **优化/统计算法（档B）**：优化模型给初始解构造、邻域/更新规则的数学表达、关键参数取值依据与收敛/终止判据；统计/预测给估计量构造（最小化什么、何时停止）与训练/验证划分口径。算法一律用**编号步骤**呈现（输入→步骤→输出），关键步骤内嵌编号公式。
- **智能优化/复杂自研算法（档B）**：编码、初始化、目标/适应度、更新规则、参数来源、终止条件、随机种子、独立运行与收敛证据，**不贴真实代码替代解释**；流程图仅限复杂自研算法（归 `mm-graphics`）。

## 4. 使用前 / 使用后

- **使用前**的量纲、极限、退化、守恒检查放在模型建立位置（见二.4）；**使用后**的误差、对比、稳定性证据紧跟对应结果；凡该问模型引用带适用域的近似，结果分析处引用判据数值回核一次（一句话结论，如"$\max|x_1|=0.59$ m $<h_0=0.99999$ m，线性恢复力近似成立"）。
- **选择性敏感度**：问题章只留一句话级提示（见四.2），深度归检验章。

# 四、结果呈现与结果分析（硬性）

## 1. 结果呈现（给什么、怎么给）

- **结果一致性（硬性）**：同一量在摘要/正文/表格/灵敏度基准/鲁棒性基线中数值必须一致，不同口径须显式说明；结果呈现处写死口径；声称"优于基准"必须给出基准的具体数值与出处。
- **表随结论设计（硬性）**：每张结果表回答一个明确问题，按用途选型——主结果表（本问最终答案；多口径裁决时即选定口径那张）、对照/验证表（解析 vs 数值、模型对比）、方案排序表；灵敏度扫描表归检验章（05b）；基准口径（参数基准、单位）写入表题或表头；关键数值在正文首次解读处复述并加粗，其余数不念。
- **代表性方程上正文（拟合类模型必做）**：除参数表外，正文给出 1~2 个代表性对象的完整数字方程，使评委不查参数表即见模型形态；方程系数必须与参数表同源一致（同一 `results/` 取数），禁止另算一套。
- **多单元汇总表**：按单元/区域/场景分别求解时，结果表逐单元一行，含决策量与指标量，末行总计；单元多时正文留汇总表，明细入附录或支撑材料并注明。
- **呈现顺序**：目标函数、约束按「1) 决策变量 2) 目标函数 3) 约束条件」组织；公式全文连续编号、引用"由式(3)可得"。

## 2. 结果分析（怎么写、写多少）

**每张图/表的分析 = 读图句 +（按需）归因/去向句**：

- **读图句（必有 1 句）**：指出图表中的关键位置与数值——峰值、交点、分界、单调区间、最优行，带单位。这是"针对图内容写分析"的底限；
- **归因/去向句（0~2 句）**：只写图表读不出的信息——机理归因（为什么是这个数/趋势）、设计含义（对后续问题决策意味着什么）、题面/假设核对结论。

**句量档位表（按图表类型）**：

| 图表类型 | 该写多少 | 构成 |
|---|---|---|
| 结论性（主结果表、最优方案、判定/排序） | 2~4 句 | 读图句 + 三段式（见下）；机理已由推导链给出时（一阶条件/闭式）引用式号即可，不重复成段 |
| 描述性（运动曲线、收敛过程、中间量、展示性图表） | 1~2 句或零解读 | 读图句（+去向一句）；禁止趋势复述段——图表本身即交付 |
| 对照/验证表 | 表后 1 句 | 两法偏差 + 一句可用性结论（如"最大偏差 0.07%，数值法可信"） |
| 灵敏度/鲁棒性 | 问题章 1 句提示 | 归因展开、大表读表指南归检验章（05b） |

- **结果描述三段式（仅结论性结果必须）**：`数值 → 机理 → 决策含义`——数值（带单位、2~3 位小数）；机理（为什么是这个数）；决策含义（翻译回题目语言），缺一不可；适用范围见上表。
- **解读信息量判据（反文字堆叠硬红线）**：解读句只写图表读不出的信息；复述图表肉眼可见内容（"先增大后减小""呈周期性"）且无归因去向的句子一律删（判据同语言冷读四问）；无信息可说时允许零解读，禁止为"有解读"堆段。
- **逐量分条与伏笔（多个结果量时）**：结果分析按量分条（①②③，每量一条），每条在"数值→机理"后落到**设计含义**——对后续问题决策意味着什么；前问设计含义应真实成为后问建模依据（伏笔兑现）。
- **参数分区间行为讨论（适用时）**：按关键参数区间逐段讨论——每段"决策对象实际在做什么 → 机理 → 行为结论（关键数值加粗）"，落到作业/取舍位置。
- **先验预测→图表核对（结果分析开头的固定动作）**：摆图表前，先从题面与模型结构推出结果应满足的性质（对称性、单调性等）写下预测，再以图表逐项核对——通过即模型正确性的独立证据，不通过回查模型。禁止只摆图不预测。
- **验证对照表（两法对照/方法标定时必做）**：复算结果与主解**同表对照**，逐项列两法取值，误差（绝对/相对）单独成行，表后一句结论收口；解析—数值双轨的"标定—推广"叙事中，本表即数值方法精度的证据（见三.2 档B）。禁止只在文字里说"两种方法结果接近"。
- **裁决式结果分析（同一量存在多个合理口径/建模方案时必做；触发：该量定义需建模者约定且题面未完全钉死）**：①各口径并列建模、各自求解成表，表题标注口径名，败者不删；②按可信度优先级选裁决手段：解析构造 > 精确作图量测 > 数值实验 > 论述，禁止以数值验证数值的循环论证；③裁决点取定性分歧处，一句话判定并声明采用口径；④选定口径单独出主结果表作为本问最终交付；正文含"口径裁决对照表"，缺表即未做裁决。

# 五、全文通用要求（硬性）

## 1. 文字密度：三不写

文字只负责"动机 + 作用"串联（获奖论文文字密度约每页 400～500 字）：
1. **中间推导量不写文字**：能用编号公式表达的量一律用公式（但公式的来源/动机仍须当众推导，见二.4）。
2. **表内数值不在正文复述**：解读按四.2"解读信息量判据"执行——只写归因、去向与核对结论；结论性结果 2~3 句，描述性结果一句或零句。
3. **建议/启示类内容不写**：各问正文不出现"对生产管理的启示"类段落，全文只收口在"模型评价与推广"章。

**3b. 解释类图只保留引用**：解释类图自明，正文不得出现"图 X 展示了…"介绍句，只以 `\ref` 嵌在讲结论/机理的真实句子里；数据结果图不适用（按四.2 分档解读）。自检：任一段落删去后论证链、数值答案、机理归因均无损失，删。

## 2. 模型链思想

见 `../common-paper-rules.md` 公共要求第 20 条（单点定义）：前问输出真实进入后问的变量/目标/约束，接口声明句 + 差异声明，只写"基于问题一"不算联动。
