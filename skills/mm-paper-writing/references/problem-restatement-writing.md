# 问题重述写法（操作规范）

> **本文件是问题重述写作的唯一操作规范**；获奖论文惯例证据（27/28 篇设置"问题重述"章）见 `corpus/章节组织-playbook.md`，两处冲突时以本文件为准。

## 1. 结构

- **1.1 问题背景**：按题目对象与背景复杂度写足实质信息，用自己的话，不抄题面。通常写 3 个左右的完整句子；简单题可 2~3 句，历史、工程或机制背景较复杂时可写 3~5 句。至少交代研究对象、现实/学术意义和题目核心矛盾中的两项，不得只用 1~2 句可替换到任意题目的套话草草带过。
- **1.2 问题提出**：逐问复述，条目数与题面问题一一对应；每问以加粗的"问题X"开头，**不加序号、不加项目符号**，便于评委逐问定位。

## 2. 写法要点

1. **只复述、不展开**：不写"我们建立 XX 模型、采用 XX 算法"等内容，建模思路属于问题分析章。
2. **禁止抄原题**：用自己的话改写；背景中的数据（如站点数、订单量）可量化，但必须是题面真实数据。
3. **语言去 AI 味**：不用"首先……其次……最后""值得注意的是""综上所述"；短句、具体动词。
4. **篇幅随题目决定**：不设置最低占页率，也不要求填满一页。问题较少或任务简单时可以明显短于四分之三页；问题较多、输入输出边界复杂时相应写长。无官方模板或用户另行要求时，整章原则上不超过一页；不得用重复题意、附件字段或空泛背景补版面。不插图、不列表、不放公式，把篇幅留给建模与结果。
5. **"问题X"加粗、不加序号**：问题条目以 `\textbf{问题一}：内容` 的段落形式写出，不加（1）（2）序号、不加项目符号；只加粗"问题X"，后续内容不加粗。
6. **LaTeX 细节**：用 `\section{问题重述}` + `\subsection{问题背景}`、`\subsection{问题提出}`；问题条目用分段段落逐条写出，空行分隔，不用 `enumerate`/`itemize`；**导言区必须设 `\pagestyle{plain}`**（ctexart 默认 headings 样式会在页眉自动放章节名和页码）；若模板要求"一、问题重述"式中文编号，另配 `\renewcommand{\thesection}{\chinese{section}}` 类设置。
7. **数据/输入说明不进问题重述**：数据、地图、参数来源、口径假设等说明不属于问题重述；内容少时并入"模型假设"或参数表下方说明，内容较多且确有必要时独立成"数据与地图"章（放在问题分析之后、模型假设之前），不得因内容少而硬凑大章节，也不得塞进问题重述。

## 3. LaTeX 示例

```latex
\pagestyle{plain} % 导言区设置：清除页眉，页码放页脚中部

\section{问题重述}

\subsection{问题背景}

共享电单车是城市短途出行的重要补充，具有随取随还、绿色低碳的特点。
但骑行需求在时间和空间上分布不均，站点容量与调度能力有限，车辆闲置
与无车可用并存，给运营商带来成本压力和体验损失。本题以某市共享电单车
运营数据为对象，研究需求预测、站点布点、动态调度与定价策略问题，为
运营决策提供量化依据。

\subsection{问题提出}

\textbf{问题一}：依据附件中的历史订单、天气和节假日数据，建立城市各区域
共享电单车日需求量的预测模型，并给出未来一周逐日、逐区域的需求
量预测结果。

\textbf{问题二}：在站点建设成本、车辆容量和覆盖半径等约束下，设计站点
选址与初始配车方案，使总运营成本尽量小、用户取还车便利性尽量高。

\textbf{问题三}：针对早晚高峰时段部分区域供需失衡的问题，建立考虑车辆
调运成本与时间窗的动态调度模型，给出调度方案，并刻画调度过程中
车辆分布的演化情况。

\textbf{问题四}：结合需求弹性与运营成本，设计分时段、分区域的动态定价
策略，分析其对平台收益、用户满意度和车辆周转率的影响。
```

> 示例题（共享电单车运营优化）仅为演示写法；实际撰写时替换为真实赛题，并保证内容与 `docs/01-analysis-report.md` 的问题重述一致。

## 4. 自检清单

- [ ] 1.1 背景是否与本题复杂度相称，并写清研究对象、意义或核心矛盾，而非 1~2 句通用套话
- [ ] 1.2 问题提出逐问覆盖，条目数与题面问题一致
- [ ] 未引入题面之外的额外要求
- [ ] 无原题原句搬运
- [ ] 无 AI 腔连接词（首先/其次/值得注意的是/综上所述）
- [ ] 问题条目不加序号、不加项目符号，仅"问题X"加粗
- [ ] 每个"问题X"已加粗，内容不加粗
- [ ] 篇幅是否随问题数量和复杂度自然变化、未强制填页，且无另行要求时整章不超过一页
- [ ] 问题重述未混入数据/地图/参数说明（这类内容已并入模型假设或参数表说明）
