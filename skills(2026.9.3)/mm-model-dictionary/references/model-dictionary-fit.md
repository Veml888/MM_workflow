# 模型与问题适配性评估（11 维中文版）

对用户选定的模型，按以下**独立维度**逐项核对，判断它是否真适合当前题目与数据。

## 11 个判定维度

| 维度 | 要回答的问题 |
|---|---|
| 1 任务对齐 | 该模型是否真正解决本题任务：描述、推断、预测、分类、排序、优化、仿真、控制还是解释？ |
| 2 观测单元 | 建模的单元是否与数据一致？重复的人/地点/设备/面板/时间点/空间邻域是否相依？ |
| 3 目标与输出 | 模型输出是否是题目要求的那一量，含不确定性、可行决策或运营阈值？ |
| 4 数据充分性 | 样本量、事件数、特征数、类别均衡、覆盖度、测量分辨率是否足够？ |
| 5 假设 | 分布、独立、平稳、线性、比例风险、凸性、光滑等假设是否可信且可检验？ |
| 6 泄漏与因果 | 是否误用了未来信息、重复主体、由目标派生变量或结局后特征？因果结论是否超过设计允许？ |
| 7 约束与机理 | 模型形式是否保留单位、守恒律、几何、容量、时序、整数性等硬约束？ |
| 8 验证 | 结果能否用合适残差、留出/分组/滚动验证、稳定性、收敛、灵敏度、基线或仿真核验？ |
| 9 可解释性 | 对竞赛问题与领域风险的说明是否充分？ |
| 10 计算 | 模型能否在时限与资源内可复现求解？收敛与随机性是否受控？ |
| 11 论文完整性 | 团队能否说明假设、形式化、求解、参数选择、结果、检验、局限与可复现性？ |

## 判定规则

- **合适**：任务与输出对齐，核心假设成立，数据充分，验证可行，无重大结构性缺陷。
- **有条件合适**：仅在特定预处理、涉因性处理、约束补充、阈值设计、验证或与其他模型组合后才可用。
- **不合适**：解决的是另一个任务，违反核心数据结构或硬约束，或即便合理调整也无法得到要求结果。
- **证据不足，待人工复核**：关键数据事实或模型身份缺失、含糊。

**不得机械平均这些维度。** 单个致命不匹配即可决定判定。避免由关联推断因果、由样本内推断泛化、由无界或未经比较的启发式结果推断最优。

## 指标路由（按任务类型放对应检验）

- **分类**：仅在有类别均衡背景下看准确率；另看 Precision、Recall、F1、ROC-AUC、PR-AUC、混淆矩阵、校准、分组验证。
- **回归**：R²、RMSE、MAE，MAPE 仅在分母有效时；残差诊断 + 分组/样本外验证。
- **时序**：平稳性、残差白噪声、滚动起点验证、逐时距误差、结构断点检验。
- **聚类**：轮廓、DBI、CH、稳定性、可解释性；聚类是否形成可用区间/分段。
- **优化**：约束可行性、目标重算、收敛、运行时长、重复运行、基线、最优性差距或最优已知比较。
- **评价/排序**：权重灵敏度、排序稳定性、指标一致性与冗余性。
- **动力/数值模型**：稳定性、误差阶、收敛、守恒/不变性、观测/仿真对比。
