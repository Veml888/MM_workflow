# mm-model-dictionary

内置 BZD 数模模型字典（5713 条模型记录），提供：① 候选模型的**知识档案**（适用场景/数据要求/关键假设/禁忌点/模型缺陷/检验方法）；② 已选模型的**适配性复核框架**（11 维 + 4 档判定）。

**定位（关键，防错乱）**：本 skill 是**共享知识库 + 参考**，不是"选型依据"。**选哪个模型仍由 `mm-modeling` 依据 `references/model-selection-matrix.md` + `references/algorithm-catalog.md` 决定**；判型与候选池由 `mm-problem-analysis` 依据 `problem-taxonomy.md` + `model-selection-library.md` 决定。本 skill 只负责**查字典补充候选信息、复核某模型是否合题**，绝不替代上述两个选型依据。字典是学习交流版参考，非绝对权威；机理类模型（微分方程、复杂优化）若字典未收录，照常人工判断，不因"字典没有"而否决。

## 定位与产出

**输入**：模型名（或候选池模型名）、当前题目与数据描述。
**产出**：字典中该模型的**知识档案表**（经 `query_model_dictionary.py` 查询）；或在需要时给出**适配性复核**（11 维逐项 + 4 档判定）。
**不产出**：不替 mm-modeling 定稿、不替 mm-problem-analysis 判型。只提供"这个模型是什么、合不合本题"的参考信息。

**该从哪个 skill 用（本 skill 被引用）**：
- `mm-modeling`（建模）：Step 3 选模型时，对命中字典的候选**查询档案**（场景/数据要求/假设/禁忌/缺陷/检验），把这些信息并入"候选模型比较表"的选择依据与淘汰条件；定稿后用 **11 维适配自检表**复核。查询入口：`python <mm-modeling目录>/../mm-model-dictionary/scripts/query_model_dictionary.py --model "<候选名>"`。
- `mm-problem-analysis`（分析）：Step 4 扩候选池时，若 `model-selection-library` 覆盖不全，可查字典**补候选**（只取名称/大类/适用场景，不拿完整档案）。查询入口同上。

## 使用协定（防止误用）

1. **只查，不改**：内置 `assets/model-dictionary.json` 为只读资产，禁止修改、删除、重导出、合并进其他库；保留 BZD 制作方、使用许可、版权与传播声明、`资料使用声明` 原文。
2. **不当作绝对权威**：字典是学习交流版参考。对影响结论的重要决策，仍查教材、论文、官方文档；字典未收录或与权威文献冲突时，以权威为准并标注`待人工复核`。
3. **不脱离选型依据**：查询结果只作为 `model-selection-matrix` / `algorithm-catalog` / `model-selection-library` **之外的补充事实**，不得替代它们作为选型理由。任何"选了这个模型"的结论，仍须能追溯到 matrix/catalog 的选用条件。
4. **按需分层**：分析阶段只取"名称/大类/场景"补候选；建模阶段才取完整档案 + 11 维复核。两阶段不与对方重复。

## 工作流

1. 读当前题目与数据描述，识别任务类型、观测单元、目标、数据形态、样本量、时间/空间结构、约束与期望输出。
2. 运行 `python <mm-model-dictionary目录>/scripts/query_model_dictionary.py --model "<模型名>"`（精确已知时加 `--exact`，需控制返回数用 `--limit`）。**不要把 8.68MB 字典全部载入回复**。
3. 对命中记录，比较名称/大类/具体分组/模型类别/适用场景/输入输出，选最相关的 1 条（同名可能用于不同场景，保留区分）。
4. 输出该模型的 **知识档案表**：记录 ID、名称、大类、分组、类别、适用场景、数据要求、原理、输入、输出、关键假设、禁忌点、模型缺陷、检验方法、`资料使用声明`（原文保留）。
5. （如需适配性复核）按 `references/model-dictionary-fit.md`（11 维中文版）逐项核对，给出最终 4 档判定：`合适` / `有条件合适` / `不合适` / `证据不足，待人工复核`；说明驱动判定的证据，不因"常用/高级"判合适。

## 输出结构

1. `当前查询`（模型名）
2. `字典中的模型信息` — 知识档案表（选中记录）
3. `与本题的对照`（选做；任务/观测单元/目标/数据充分性/假设/约束/验证 的简要对照）
4. `适配性判定`（选做，11 维逐项 + 4 档结论）
5. `参考依据`（指明这只是一条字典记录，选型仍以 mm-modeling matrix/catalog 为准）

- `assets/model-dictionary.json` 只读；不得修改/删除/重导出/转存为其他库，保留根节点版权、许可、违规警告、`资料使用声明` 原文与 `BZD数模社制作` 署名。
- 不输出整个字典、不批量导出、不创建派生数据库；只返回当前任务需要的最相关记录与合理替代。

- 不暴露无关记录；只返回当前任务命中项与合理替代。
