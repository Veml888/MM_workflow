# 模型选型矩阵（问题类型 → 候选 → 选用条件）

选型按"先看数据与目标，再看约束"，不要在没看数据前就锁定某个"高级算法"。

## 优化类选型

| 情形 | 首选 | 备选 |
|---|---|---|
| 目标/约束都线性，变量连续 | 线性规划 | — |
| 有整数/0-1 决策，规模小 | 整数规划(精确) | GA/SA |
| 组合爆炸、NP-hard | 智能优化(GA/PSO/SA) | 贪心+局部搜索 |
| 多目标冲突 | NSGA-II | 加权转为单目标 |
| 带随机性 | 随机规划 / 蒙特卡洛 | 期望值模型 |

## 预测类选型

| 情形 | 首选 | 备选 |
|---|---|---|
| 单变量、有明显趋势/季节 | ARIMA / Holt-Winters | Prophet |
| 多特征表格数据、样本足 | XGBoost/随机森林 | 线性回归做基线 |
| 小样本、需解释 | 线性/岭回归 | SVR |
| 长序列、大数据 | LSTM | GRU |
| 样本极少（<30） | 灰色预测 GM(1,1) | 指数平滑 |

## 评价类选型

| 情形 | 首选 | 备选 |
|---|---|---|
| 有专家成对打分 | AHP | 模糊综合评价 |
| 只有指标数据、要客观 | 熵权法+TOPSIS | CRITIC+TOPSIS |
| 指标边界模糊/定性多 | 模糊综合评价 | 灰色关联 |
| 多投入多产出效率 | DEA | 熵权+TOPSIS |

## 分类类选型

| 情形 | 首选 | 备选 |
|---|---|---|
| 二分类、要概率解释 | 逻辑回归 | LDA |
| 高维小样本 | SVM | 朴素贝叶斯 |
| 表格数据、追求精度 | 随机森林/GBDT | 决策树(需可解释) |
| 图像 | CNN | 迁移学习 |

## 机理类选型

| 情形 | 首选 | 备选 |
|---|---|---|
| 有明确微分方程 | ODE/PDE 建模+数值解 | 系统动力学 |
| 随机扩散/传染/排队 | 蒙特卡洛 / 元胞自动机 | 随机过程 |
| 需直观推演规则 | 元胞自动机 | Agent 仿真 |

> **复杂化提示**：上表是"常见层"做选择；当题面含**动态/随机/博弈/网络/多目标/容量/整数性/多物理场**等结构时，须沿 `algorithm-catalog.md` 每类的"复杂化路径"升级，不得因表里只给简单首选而忽略题面的结构难度（见 mm-modeling SKILL §五 复杂度四维审计）。简单模型"够用"是可接受结论，但"题面要求复杂、模型却简化去凑"是硬伤。

## 决策原则

1. **匹配优先**：为每个子问题选"与题目结构、数据、目标、约束真正匹配"的模型——选型依据 `model-selection-matrix`、`algorithm-catalog` 与字典档案，判断是否匹配看四点：① 题面核心结构（动态/随机/博弈/网络/多目标/机理…）是否被显式建模；② 数据能否支撑该模型的假设与参数；③ 能否产出题目要求的结果；④ 能否在论文里讲清"为什么用、怎么验证"。**不以复杂/简单定优劣**——只要真正匹配（结构建成、数据支撑、可解释、可复现、可验证），无论简单或复杂都可以用。
2. **不为偷懒简化**：题面含动态/随机/博弈/网络/多目标等结构时，必须显式建模这些结构(见复杂化路径)，**不得为"省事"而用不匹配题面的简单模型**；反之，简单模型若能完整匹配并验证，也为可接受结论，不为凑复杂而复杂。
3. **可复现优先**：随机方法固定种子；优先 scipy/sklearn 等主流库，避免生僻依赖。
4. **可解释优先**：模型要能在论文里讲清"为什么用它、参数怎么定"。
5. **数据真实**：所有参数来自题面或可核验来源，不得编造。
6. **有对比**：关键子问题给出备选模型，用指标对比证明所选模型更优。
7. **验证配套**：凡所选模型（无论简单复杂），须配与之匹配的验证证据（结构/统计/对比/灵敏度/鲁棒性，见 mm-modeling SKILL §四）。简单并不意味着"免验证"，复杂也不意味着"自动更可信"。
7. 每个子问题在建模报告中写一句"选型依据"，把选型矩阵里的判断落成文字。
