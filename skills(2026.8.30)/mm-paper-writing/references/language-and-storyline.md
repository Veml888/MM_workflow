## 一、语言自然化与去 AI 味

用于 CUMCM 论文的语言层与最终自然化审校。目标是让论文具有学生团队基于真实工作写成的具体、克制和连贯表达，同时如实保留 AI 使用说明。

**执行顺序**（不得先改文风再补技术内容）：① 依据题面、模型、代码、结果和图表完成技术上成立的初稿 → ② 逐段检查材料、证据和推导是否足以支撑结论 → ③ 结合上下文自然化措辞、合并重复、修复断裂 → ④ 清除正文、图表和附录中的生成过程残留 → ⑤ 重新核对技术事实、结论强度和完整论证链。

**技术保真硬门槛**：自然化不得新增、删除或改变题面条件/样本范围/数据字段口径；数字、单位、精度、参数、公式、约束、变量定义；模型选择理由、算法步骤、实验设置与评价标准；相关、因果、显著性、最优性、稳定性和泛化性的结论强度；失败结果、不确定性、适用范围和限制条件；图表含义、文献来源和正文交叉引用。每个关键结论必须沿"结论→结果→模型→数据或题面"反向追溯；无法追溯的不得靠润色保留。不得编造案例、机制、实验、参数、文献或精确细节；信息不足时写清可观测量、必要假设、待估参数和适用边界，不用语言掩盖缺口。

**以材料推动段落**：每段只承担一个主要功能，新段落必须增加至少一种实质内容（事实、定义、公式、推导、数字、比较、选择理由、失败结果、限制或对下一步的作用）。用信息增量判据：删除某句后事实/逻辑/边界/结论均未减少，则该句通常只是表演条理、深刻或文采，应删除；不得删去承载因果、转折、定义、范围或推导作用的句子。复杂分析段检查"论点—依据—推导—结论"是否齐全。避免只有观点没有依据、只有数据没有解释、只有公式没有用途、先给强结论再用模糊语言补理由、用"显然/容易看出"跳过关键推导。

**面向人的论证逻辑**：正文按`题目要求 → 现实障碍 → 数据与假设 → 选择理由 → 模型与求解 → 结果证据 → 决策含义 → 适用边界`推进。先说明要解决的具体困难，再引入变量/公式/算法；先解释选择依据，再报告模型结果；结果段同时回答"数值是多少""说明了什么""对题目哪一问有用"；小节之间用前一节结论承接下一节，不用"进入下一阶段""根据流程安排"等内部流程语言；允许不同问题使用不同叙事结构；删除只宣布"本文完成了什么"而没有增加事实/依据/边界的句子。

**题目要求约束**：论文只写题目需要回答的内容。动笔前把题面拆成可核对的子问题和硬性输出，建立内部追踪表`题面要求/子问题 → 正文位置 → 模型或计算 → 图表/数值证据 → 结论`；正文不展示这张表，也不把 `P-##`、`REQ-###` 等编号写给读者。以下内容不得因"常见/有价值/能增加篇幅"而加入：题目没要求且不改变判断的背景扩展；与当前数据/约束无关的模型介绍、算法比较或理论综述；没有对应题面决策的灵敏度、鲁棒性、推广和评价；不能支持结论的装饰性图表和重复解释。写完每个问题必须用明确结论回答题面动词（预测/优化/比较/安排/解释/建议）。

**高频模板痕迹与处理**：以下项是风险信号，不是机械禁词；只在空转、堆叠或重复时才删除或改写。连续"首先/其次/最后"（提纲替代论证）；"值得注意的是/综上所述/总而言之"（无信息路标）；每段以"本文/我们"开头（主语单一）；"精准/高效/深入/显著提升"（评价无证据，换成误差/耗时/指标/区间/对比）；"进行建模/开展分析/实现优化"（动词空泛，直接写建立/拟合/求解/检验/最小化什么）；同义词轮换术语（定义漂移，统一唯一名称）；"不是 X，而是 Y"式虚假对立（若删除 X 后信息不减，直接陈述 Y）；整齐等长句/排比段（节奏机械）；人为金句/宏大意义/乐观收尾（超出证据）；多重保留词叠加（判断含混）；无来源权威表述；熟悉名词反复加引号/重复括注。冒号、破折号、"不是…而是…"、因此/此外/然而等不设绝对禁令，承担定义/对比/因果/转折功能时可用；数学箭头保留标准含义，正文叙述中装饰性箭头改正常文字；编号按内容选择并保持全文协调。

**数模论文自然表达**：量化优先、动词具体、减少空壳名词化、语气克制（区分实测/模型估计/统计关联/机制解释，不写"完美解决""完全正确"）、长短句配合、术语稳定（首次给出中文全称与缩写，后文统一）、自评绑定证据、"精度较高/模型稳定/优于基线"必须紧邻指标/误差/对照结果、限制写成边界（"在当前样本范围内""在上述假设下"）。

**保持完整学术叙事**：形成连续链条`题目要求 → 数据与约束 → 必要假设 → 模型选择 → 变量/目标/约束 → 求解 → 结果 → 验证 → 适用边界 → 对题目的回答`。逐章排查断裂：问题分析提出的因素后文未使用；变量/公式突然出现；模型与结果用不同口径；结果只报数字不回问题目；验证与前文模型无对应；评价与真实实验脱节；结论新增正文未论证观点；各小问像独立文本拼接。公式出现前说明动机、服务对象和变量来源，出现后说明如何进入计算或推断；图表出现前说明查看目的，出现后解释最重要的现象、比较和后果。

**成稿禁用表达与唯一例外**（竞赛成稿硬性语言门禁，适用于标题/摘要/关键词/正文/图题/表题/图表可见文字/附录说明/页眉页脚；不适用于完整源代码、程序输出、公式变量名、文献题名或逐字引文）：
- 生成过程与工具身份：`AI`、人工智能、大语言模型、ChatGPT、Codex、Agent、智能体、提示词、Prompt、skill、工作流、阶段、上游、下游、GATE、manifest、artifact、调用、生成、自动生成、用户、本助手；
- 对话与执行口吻：根据你的要求、下面给出、如果需要可以、接下来、下面由、已完成此阶段、我/我们为你；
- 空泛模板与无证据自评：本文将、值得注意的是、需要指出的是、综上所述、总而言之、形成闭环、完整回答、显著提升、有效赋能、可解释性强、具有重要意义。

这些禁用项不能靠同义替换保留原有空话；应删除无信息句，或改为可核验的题面条件、模型定义、数字、比较结果、推导理由和适用边界。技术上必须使用"生成"等字样时，用精确学科术语重述；无法重述须向用户说明冲突。**唯一例外**是每篇论文必设且置于参考文献之前的"AI 工具使用声明"，其前后可用源码注释 `% language-audit: allow-start` 和 `% language-audit: allow-end` 标记供审校脚本跳过；豁免标记不得包围其他正文、图表文字或附录说明。终稿前运行 `python <mm-paper-writing目录>/scripts/audit_submission_language.py paper`；命中项必须逐处人工判断，脚本通过不替代逐页目检。

**清除生成过程残留**：交付前检查摘要、标题、正文、图题表题、表内文字、图内可见文字、公式说明、页眉页脚、参考文献和附录，清除对话式提示、Prompt/TODO/placeholder/待补充/待验证/此处放图/内部备注、"由 AI/ChatGPT 生成"、模型建议、审稿备注、工作流说明、LaTeX 注释误渲染出的内部信息。残留已嵌入图件则回写画图阶段重新导出。AI 使用情况在官方要求位置如实披露，不以删除痕迹代替披露。

**最终自检**：每段增加实质信息、无同义灌水；删除铺垫/收尾句后信息不减则已删；套话按语境处理、无机械禁词替换；无虚构对立面、弱动词名词化、重复引号和装饰性括注；结论有数字/公式/图表/来源支撑；术语/符号/单位/精度/结论强度一致；生硬句结合前后文修复、段落逻辑连续；公式/图/表正确引出并得到实质解释；没有新增事实/实验/机制/结果/文献；无 Prompt/占位符/内部备注/生成过程提示；AI 说明真实完整符合要求；成稿禁用表达通过脚本与人工复核、唯一豁免为 AI 声明；每节能独立回答"解决什么问题、依据是什么、为什么这样判断、如何回应题目"；题面每项要求都有模型/证据/结论落点。

## 二、故事线（降低模型腔 + 冷读）

全文按"问题 → 障碍 → 选择 → 证据 → 转折 → 决策 → 边界"推进，不用文学比喻。每一节开头承接上一节留下的具体问题，结尾落下一个可复算结论并自然引出下一节；衔接靠事实，不用"下面进一步研究"。摘要为全文故事缩写（数据困难→字段处理→模型→测试结果→关键因素→审核决策→创新点→适用条件）；结论按问依次回答、每段含方法/数字/判断、最后一句只写应用条件、不重新总结全文。

**降低模型腔**：每个主要段落加入数字、公式、字段关系、程序结果、失败结果或选择理由；效果有限时直接写 AUC、区间、Lift 和名单稳定性；写清放弃复杂模型、固定分层或虚假概率解释的原因；相同限制只在摘要、结果和结论各保留必要一次；技术名词一致，不做无意义同义词轮换；段落长度随内容变化；删除"本文将从三个方面展开""值得注意的是""需要指出的是"等路标；删除"完整回答三问""形成可执行闭环"等空泛评价；图题和表题不写作者备注、读图提示和后续计划；不在正文保留给模型或作者自己的提示语。

**冷读检查**（完成初稿后对每段问四问）：① 这段新增了什么证据？② 能否原样放进另一篇论文？③ 结论是否超过材料？④ 删掉最后一句是否更有力？没有新增信息的段落合并或删除。
