# 篇幅控制

> **定位：正文页数的操作规范**（27–30 页为硬性门禁）。篇幅不足怎么补、超过怎么减、什么算注水、补完怎么验，都集中在这里；它是撰写与终审的必读项，`read_complete.py` 会按注册表强制读取。不涉及图表锚点/浮动留白类视觉问题（那归 `layout-and-compilation.md`）。

## 1. 正文边界与页数门禁

- 正文 = 摘要之后、附录之前（含顺序章节、AI 工具使用声明、参考文献），**不含摘要和附录**。
- 正文默认 **27–30 页**，策划目标为 28–29 页（给分页波动留余量）；以当年官方规定为准。
- 一键核验：运行 `python <mm-paper-writing目录>/scripts/check_paper_length.py paper/论文.pdf`；不在 27–30 内脚本非零，必须继续修订，直到 exit 0。

## 2. 篇幅不足（<27 页）怎么补

**① 先定位，再动手**：跑 `check_paper_length` 确认真实页数；对照 `page-budget.json` 看哪一章没达到 `min_pages`、哪章超标；看 `content-gap-report.md` 有无未关闭的阻断项。**不要一上来就加字，先确认缺在哪、是哪些内容支撑不足。**

**务必区分两类缺口**：
- **真不足** = 论证、证据、对题面的回答缺内容；
- **视觉缺口** = 图表锚点/浮动造成的留白。此时优先调锚点、浮动参数、关联图组合，**而不是加字**。视觉缺口归 `layout-and-compilation.md`，本 playbook 只管"内容不足"。

**② 补的优先级（从最有价值到最无价值）**：
1. **缺题目要求的最终答案** → 补"直接回答题面"的汇总句/表。最常见也最值钱——多数正文不足其实是"过程完整但答案没写清"，补一个答案汇总段既涨篇幅又直接服务评分点；
2. **缺推导链/机理** → 补公式的引入理由 + 每一项的现实含义（不是加公式数量，让每个公式承担一个作用）。**并可把"一步带过"的推导展开为更细的多步过程**——如"由几何关系得 λ*"展开为"逐量定义 → 列几何/距离关系 → 逐步推导 → 说明每个符号含义"；"求导得最优解"展开为"写目标函数 → 对 x 求导 → 令导数为 0 → 解出 x* → 检查二阶条件/边界 → 说明为何可行"；"积分得遮蔽时长"展开为"确定区间 → 拆时间段 → 逐段积分 → 汇总"。**判据：展开后读者更能理解这个公式为什么成立、怎么来的，且每一步可追溯、每步有独立信息——这是实质内容不是注水；若只是把一句话拆成三句同义反复，或堆叠与本题无关的通用数学定理/教材公式，就是注水。**
3. **缺验证证据** → 补检验/灵敏度/鲁棒性的具体数值 + 解读（给对象、指标、量级、对比基准，不说空话）；
4. **缺结果解释** → 补结果"数值→机理→决策含义"三段式的后两段；
5. **缺图表** → 补数据图/机理图，但必须有正文引出 + 实质解读，不能孤图。

**③ 什么算"实质内容"、什么算"注水"**：
- **实质内容** = 删去后，论证/边界/证据/对题面的回答会损失；
- **推导展开（补篇幅常见且正当）**：把"一步带过"的推导展开为多步、每步有独立可追溯信息、能让读者更懂公式为何成立——属实质内容；反之，把一句话拆成几句同义反复、或堆叠与本题无关的通用公式/定理，属注水（判据见上文②）；
- **注水** = 删去后无损失，或为填页重复题意、重复图表、凑字数的套话；
- **禁止**：为补篇幅编造数据/结果、重复论述、无信息图表、`\vfill`/弹性空白、异常放大标题/字号、缩小页边距、加空行、手工换行填页、因页数而在问题重述/问题分析里注水。

**④ 补完怎么验**：
- `check_paper_length` exit 0（落在 27–30 内）；
- `check_layout` 无大段空白/孤立图页；
- `audit_submission_language` 无 AI 腔/空泛评价/注水词；
- 逐段冷读"删去这段，论证/边界/证据有没有损失"（复用 `layout-and-compilation.md` 的人工冷读门禁）。

**⑤ 补在哪一章（必须遵守各章骨架，不可改）**：正文不足先看 `page-budget.json` 各章实际 vs `min_pages`，**缺在哪一章就在那一章"允许的骨架内"补**；不同章的可补性不同，且**不得为凑页数改变或新增固定骨架**：

| 章节 | 固定骨架/限幅（不可违背） | 能否补篇幅 | 能补什么 |
|---|---|---|---|
| 01 问题重述 | 仅三小节（背景/提出/综述）；全章约 1–2 页、不插图不放公式不列表 | **基本不可补** | 只微调背景的"改写"程度；不靠它撑页数 |
| 02 问题分析 | 每问一小节；不设总体/额外子标题；无最低占页率 | 可补，但约束严 | 只在某问缺"任务边界/数学类型/主要困难/方法依据/跨问依赖/验证方式/交付形式"时补；**不得为填页重复题意、堆方法** |
| 03 模型假设 | 编号列表 2–8 条、每条单独成段 | 8 条内可补 | 补某条假设的来源分类、三要素、违背影响；**不新增无关假设凑数** |
| 04 符号说明 | 单个三线表（符号/含义/单位），不收一次性符号 | **不可补** | 不靠它撑页数 |
| **05 模型的建立与求解** | **无固定骨架**：外层按题面问题顺序、内层按机理/数据/目标/约束/算法/结果/验证实际需要组织，**可灵活增设小节/三级标题** | **最能补（主补点）** | 补公式引入理由、**展开推导步骤**、验证证据、结果解释、图表（正文论证主体） |
| 06 模型评价与推广 | 依次三节（优点/缺点/改进）；通常半页–1 页、≤正文 3%–5% | **基本不可补** | 只把优点/缺点/改进写实在；不靠它撑页数 |

**06 无固定骨架但禁止假大空（模型章专属红线）**：模型章虽可自由增小节，但**每增一个小节/段落必须是"实打实的内容"**——具体数据、公式推导、参数来源、结果数值、验证证据、图表解读。**禁止假大空**：空泛套话（"模型适用性强""经过分析可知"）、无数据泛泛而谈（"深入挖掘数据得到规律"但没说哪个数据/什么规律/数值多少）、无指标的"效果良好"、复述建模意义、堆课本概念。**判据**：删去这段后，论证/证据/对题面的回答是否有损失？有损失 → 保留（真内容）；无损失只"显得完整" → 假大空，删。

## 3. 篇幅超出（>30 页）怎么减

- 优先删**注水**（重复论述、无信息图表、可合并句子、应移到他章的细节），而非砍必要论证。
- 再压缩**非核心**：次要辅助模块只需在附录 A 登记、不放正文；啰嗦的过渡句合并；无独立结论的中间图删掉或合并。
- **禁止**为减页牺牲对题面的完整回答、删除必要验证证据、把字号缩到小于五号、删核心逻辑。

## 4. 与相邻规范的分工

- **本 playbook**：只管"内容不足/超出的页数控制"（怎么补实质内容、怎么减注水）。
- **`layout-and-compilation.md`**：管"视觉留白/浮动/图表锚点"类排版缺口，以及 `Overfull`、字号、间距。
- **`common-paper-rules.md` 第 5/6 条**：正文边界与"不为页数扩写"的底线，指向本 playbook 执行细则。
