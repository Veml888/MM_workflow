# 获奖论文写作惯例语料（corpus playbooks）

本目录的 playbook 提炼自 **2020–2025 年 28 篇国赛（CUMCM）优秀论文**的语料统计，每条规则标注支持篇数（如 28/28、20/28）。它只提供"怎么写才对味"的**写作技艺参考**；固定格式和论文交付要求以 `mm-paper-writing/SKILL.md` 为准，跨阶段真实性与追踪遵循共享不变量。本目录中的字数区间、章节骨架、图表数量、检验手段和措辞用于辅助写作判断，不单独构成硬性规则来源。

两者冲突时，**官方优先**。

## 文件与用途

| 文件 | 用途 |
|---|---|
| `摘要写作-playbook.md` | 摘要字数、逐问分块结构、数字密度、关键词 |
| `章节组织-playbook.md` | 八段式章节骨架、各标准块写法、篇幅基线 |
| `模型检验与评价-playbook.md` | 检验手段清单、灵敏度写法、评价三段式（示弱） |
| `图表规范-playbook.md` | 图/表数量基线、标题格式、三线表、图种 |
| `语言与措辞-playbook.md` | 过渡词、主语规范、自评与数字绑定 |
| `易错点与反模式-playbook.md` | 真实反例清单、赛前检查清单 |

> 说明："问题重述""问题分析""建模与求解"的写作规范已并入 `mm-paper-writing` 的 `SKILL.md`（见其"问题重述写作""问题分析写作""模型建立与求解写作"三节），不再作为 corpus playbook 维护；其语料证据（27/28、26/28 篇设置对应章节；建模与求解的 28 篇共性 + 六篇拆解随文件保留）不再重复维护于本目录。

## 语料来源与偏差（诚实边界）

- 语料：2020–2025 高教社杯国赛优秀论文 28 篇（2023 年 13 篇文本直转 + 2020-2022/2024-2025 各年 A/B/C 抽样 15 篇 OCR）。
- 抽样偏差：2023 年权重偏高（13/28），D/E 题样本仅 3 篇（均 2023）；OCR 篇目公式/表格有识别噪声，规则基于正文文字层。
- 这些规则只能判断"写法是否符合获奖论文惯例"，不能判断模型是否合理、结果是否正确。
- 竞赛规范随年份变化（篇幅、提交格式、2025 年起 AI 使用披露），交付前核对当届官方文件。
- `mm-paper-writing/SKILL.md` 的"模型建立与求解写作"节含**六篇**优秀论文的深度拆解（商超定价补货、古代玻璃成分分析、企业原材料订购运输、NIPT 检测决策、生产检测拆解决策、同心鼓），覆盖优化/数据统计/物理机理/概率序贯决策四类题型；其"论证逻辑"跨题通用，但"模型组合、求解算法、预处理篇幅、模型链形态"均需按题目实际调整，不得生搬硬套。

> 原始语料清单与逐条证据映射见原 skill 的 `references/research/`（本目录为精简版，未随附研究证据，避免体积膨胀）。
